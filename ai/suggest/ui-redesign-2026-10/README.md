## 打开方式

浏览器（Edge / Chrome）直接打开 `index.html` 即可，无需构建。顶部控件：

- **方案切换**：现状 / A 墨 / B 纸 / C 琉 / A+B 推荐；
- **并排对比现状**：左「现状基线」右「当前所选方案」同屏对照；
- **深浅主题**切换。

支持 URL 参数深链：`?scheme=ink|paper|glass|combo|current&theme=light|dark&compare=0|1`。

`shots/` 内为评审用截图（Chrome 无头模式渲染）。

## 诊断结论（年代感来源）

1. 配色为 2014–2017 GitHub Primer 配方（`#4078d3` + 冷灰 + 全描边）；
2. 边框撑起整个界面，缺乏明度分区与阴影层级；
3. Windows 首命中字体为微软雅黑，字号体系扁平（11–14px 挤在一起，层级靠变灰）；
4. Element Plus 出厂形态未精修（弹窗/按钮/输入框骨架样式与应用两张皮）；
5. 细节 token 无体系：圆角 4–20px 混用、动效仅背景色过渡、常驻滚动条、蓝紫渐变 logo；
6. 排版是「GitHub 技术文档」式（标题下划线、全网格线表格）。
