# 右键上下文菜单与轮盘菜单可行性（提案，待定）

> 2026-09-30 用户咨询「右键空置，有无推荐功能；右键轮盘在现有框架下能否实现」。本文为建议存档，未立项。

## 现状

全应用 **0 处 `contextmenu` 处理**：编辑器内右键弹的是 **Chromium 原生菜单**（复制 / 粘贴 / 检查——打包后带「检查」项，观感是开发态残留，是全应用最「出戏」的一处）；侧栏树、网格卡片、标签、回收站全靠 `⋮` 按钮触发 el-dropdown，动作齐全但入口单一（必须先精准悬停到小按钮）。

## 推荐的右键功能（按表面分，P1 优先）

### P1 · 编辑器右键（价值最高——原生菜单替换 + 选区动作）

| 上下文 | 菜单项 |
| --- | --- |
| 任意 | 剪切 / 复制 / 粘贴（粘贴走 CM 管线，自动享受 FR-2.4.25 归一化，见技术注意点 ①） |
| 有选中文字 | 加粗 / 斜体 / 删除线 / 行内码 / **转为双链 `[[选中]]`** / 复制选中 |
| 光标在链接上 | 打开链接 / 复制链接地址 |
| 光标在图片上 | 在附件目录中显示（资源管理器定位）/ 复制图片 |
| 光标在双链上 | 打开笔记 / 复制 `[[引用]]` 文本 |

「选中即转双链」是其中最高频的新能力（现需手动输入 `[[`）。

### P2 · 树 / 网格 / 标签 / 回收站右键（镜像既有 ⋮ 菜单，零新逻辑）

| 表面 | 菜单项 |
| --- | --- |
| 侧栏树（库 / 文件夹 / 笔记） | 镜像各自 ⋮：新建、重命名、移动、收藏、标签、信息、导出、分享、Git 菜单、删除（红） |
| 网格卡片 | 镜像卡片 ⋮ |
| 标签行 | 重命名 / 改色 / 删除 |
| 回收站条目 | 还原 / 彻底删除 |

做法：把各处 `⋮` 的菜单项定义抽成可复用的 items 数组（文案 / 图标 / handler / danger 标记），dropdown 与 contextmenu 共用同一份——动作永不分叉。

### P3（可选实验）· 轮盘菜单

见下节结论：**不做全局轮盘**；若要尝鲜，唯一合适切入点是「编辑器有选中文字」场景的固定 6 项格式轮盘（加粗 / 斜体 / 删除线 / 行内码 / 双链 / 复制），设置开关默认关。

## 轮盘可行性评估

| 维度 | 结论 |
| --- | --- |
| 技术可行性 | **完全可行**。Electron 无原生轮盘，需自绘 Vue 组件：绝对定位 + CSS 扇区（`clip-path` / conic-gradient）+ pointer events，无框架障碍，含动画与 Esc / 点击外部关闭约 2 天 |
| UX 是否推荐 | **全局轮盘不推荐**。轮盘的优势场景是「固定 4~8 项高频动作的免视操作」；笔记应用的右键动作是分层且随上下文剧烈变化的（树节点 ≠ 选区 ≠ 链接），硬塞轮盘需要二级分页反而更慢；且与既有 ⋮ 菜单形成双入口，用户学习与代码维护双份成本。Windows 用户对右键的预期是标准上下文菜单 |
| 若要实验 | 唯一合理切入点 = 编辑器选区格式轮盘（固定项、无层级、高频）。建议作为实验特性设置开关默认关，收集一段使用反馈再定去留 |

**结论：推荐做标准上下文菜单（P1 + P2），轮盘列为可选实验（P3）或不做。**

## 技术注意点（既有教训挂钩）

1. **右键粘贴的管线选择**：FR-2.4.25 归一化挂在 DOM `paste` 事件——直接 `dispatch(replaceSelection(剪贴板文本))` 会**绕过归一化**。两条路：主进程 `webContents.paste()`（走原生路径、保留事件，推荐）或 dispatch 前手动过 `normalizeInvisibleChars`。剪切同理由主进程 `cut()` 承接；
2. **上下文判定用 `posAtCoords`**：注意其对原子 widget 返回区间外位置（±1 容差，09-30 教训 4）；
3. **自绘菜单的 popper 残影**：菜单项触发删除 / 收起容器时需 menu-hold 模式（锚点保持或 ≥300ms 延迟，既有教训）；
4. `el-tooltip` 禁令不适用（右键菜单无 tooltip），但菜单内 danger 项红色警示、删除走 ElMessageBox 确认——注意 EP 2.x 无 `__wrapper` 类（09-30 教训 1）；
5. **防默认菜单范围**：编辑器 `preventDefault` 后自绘；输入框（设置页 / 过滤框）可保留原生（有系统拼写 / 粘贴能力）或同样替换，二选一拍板。

## 工时评估

| 批次 | 内容 | 工时 |
| --- | --- | --- |
| P1 | 编辑器右键（剪贴板 IPC + 上下文判定 + 菜单组件 + 选区动作） | 1~1.5 天 |
| P2 | 树 / 网格 / 标签 / 回收站右键镜像（items 抽取复用） | 0.5~1 天 |
| P3 | 选区格式轮盘（可选实验，设置开关） | 约 2 天 |

## 非目标

- 不做全局轮盘主菜单（理由见上）；
- 不做右键子菜单超过两级（标准上下文菜单保持扁平，低频动作留在 ⋮ 菜单）；
- 暂不做拼写检查建议项（应用无拼写检查体系）。
