# 斜杠命令（FR-2.4.22）

> 2026-09-26 立项（用户提案池 [#4](../../suggest/feature-proposals.md) 迁入）。设计文档：待设计。工时评估（建议阶段）★★，1~2 天。

## 需求背景

编辑动作目前靠工具栏按钮与快捷键触发；「手不离键盘」动线（心流模式，FR-2.9.8）下还缺一个不用记快捷键的入口。斜杠命令把既有编辑动作「命令化」：输入 `/` 呼出命令列表，继续输入过滤，选中执行——与语雀等同类的交互形态。

## 需求

### FR-2.4.22 斜杠命令

- 编辑器内输入 `/` 触发命令列表（补全面板形态），继续输入按命令名 / 别名过滤，方向键选择、回车执行；
- **一致性原则（用户强调）**：斜杠命令是既有工具栏 / 快捷键动作的**命令化封装**，行为必须与对应快捷键完全一致（同一函数调用），不得出现两套行为：
  - `/表格` / `/t` —— 同 `Ctrl+T`（弹出尺寸输入提示态，FR-2.4.20）；
  - `/标题1` … `/标题6`、`/标题0` —— 同 `Ctrl+1…6` / `Ctrl+0`（FR-2.4.15）；
  - `/公式`、`/代码块`、`/引用`、`/任务` —— 同工具栏对应按钮（智能插入 / 占位符选中）；
  - `/分割线`、`/日期` —— 插入片段；
- 适用范围：源码与所见即所得模式均可用（CM 层统一实现），心流模式自然可用；
- **激活策略**：`/` 在正文中是普通字符（URL、`2026/09/26`）——仅行首 `/` 或「/ 后接字母」时触发，其余场景不呼出；误触发 `Esc` 关闭即可；
- 与 `[[` 补全互斥由 CM 补全机制自然保证（同时只开一个）；IME 组词期沿用既有冻结经验。

## 验收标准

1. 行首输入 `/` 呼出命令列表；正文中 URL / 日期里的 `/` 不触发；
2. 逐条执行命令，行为与对应快捷键 / 工具栏按钮完全一致（同输入场景对比）；
3. 过滤（含中文命令名）正常，Esc 关闭后 `/` 保留为普通字符可删除；
4. `[[` 补全与斜杠命令不同时弹出；所见即所得与源码模式行为一致；组词期无抖动。

## 备注

- 命令注册表复用工具栏 / 快捷键的既有函数，新增动作时两处同步登记（设计时明确单一数据源）；
- 待设计问题：命令清单的初始规模、别名机制、是否开放给插件命令（FR-2.11 体系）。
