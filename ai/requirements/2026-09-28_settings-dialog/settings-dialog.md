# 设置弹窗化与分类分栏（2026-09-28）

## 背景

设置项随版本持续增多（通用标签下十余个分组），整页视图来回切换成本高；用户要求改为
弹出窗口（`Ctrl+,` 呼出 / 再按关闭），并按功能分类、左右分栏呈现（左分类导航 + 右内容）。

## 需求（FR-2.10.3 / FR-2.10.5 扩展）

- 设置以居中弹窗呈现（约 920px 宽 / 82vh 高，遮罩半透明），`Ctrl+,` 呼出、再按关闭；
  `Esc` / 点击遮罩 / 右上 X 同效；欢迎页（无笔记）同样可打开。
- 编辑视图在弹窗下**保持挂载**：设置往返不再卸载重挂编辑器——「设置往返光标丢失」
  与「心流内 Ctrl+, 往返后快捷键失效」两类问题的机制根源（视图卸载重挂）一并消除。
- 设置项按功能分类：**账号 / 通用 / 外观 / 编辑器 / 心流模式 / 同步与数据 / 插件** 七类，
  左侧分类导航 + 右侧该分类内容；原「通用」长列表按功能拆分入各分类。
- 界面保持 Trace 风格（主题变量 / 圆角卡片 / EP 组件），原「返回编辑」按钮由弹窗
  关闭（X / Ctrl+, / Esc）替代，关闭即恢复编辑器焦点。

## 设计与实现

- 状态机制不变：仍以 `app.view = { name: 'settings', tab }` 表达打开态与当前分类，
  仅渲染方式变化——`App.vue` 的 `EditorView` 的 `v-if` 扩为 `editor || settings`
  （编辑器保活），`mainView` 移除 settings 分支，`SettingsView` 以覆盖层组件渲染。
- `SettingsView` 根结构：`.settings-overlay`（遮罩，`@click.self` 关闭）→
  `.settings-dialog`（卡片，header + columns）→ `.settings-columns`（左 `.settings-nav`
  分类导航 148px + 右 `.settings-content` 独立滚动）。
- 关闭语义收敛为**无条件关闭** `backToEditor()`：有笔记回编辑（恢复焦点），无笔记回
  欢迎页——修复欢迎页打开设置时 X 失效（旧实现带 `editor.current` 早退）。
- 分类的 tab 值集合扩展为 7 类（`view.tab` 运行态，不持久化）。

## 分类映射（原「通用」拆分）

| 分类 | 内容 |
| --- | --- |
| 账号 | GitHub 令牌登录 |
| 通用 | 工作区、侧栏菜单、快捷键速查、关于 |
| 外观 | 主题、配色、导入主题、窗口效果、窗口不透明度 |
| 编辑器 | 字号、默认编辑模式、编辑位置、表格默认尺寸、自动保存、专注隐藏顶栏、显示反向链接、跨库引用免确认 / 目录 |
| 心流模式 | 写作栏宽、底色 / 纹理 / 过渡、回车音效全套 |
| 同步与数据 | 自动同步、网络代理、回收站保留 / 容量、Git 信息 |
| 插件 | 插件市场、已安装插件、权限确认 |

## 实施记录（feat/settings-dialog）

- 模板重组采用基于标记的分割（`name=` / `settings-block` 前瞻分割 + div 平衡校验 +
  h3 / 块数不变量断言）——行号手术曾两度错切（误删 script 段 / 错删模板尾），教训：
  大段模板重组禁用行号切片，改用标记分割并加不变量断言。
- CDP 验证：Ctrl+, 开关 / Esc / 点遮罩 / X / 分类切换 / 编辑器保活 / 光标保持全过。
