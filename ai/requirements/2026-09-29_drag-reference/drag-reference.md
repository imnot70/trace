# 拖曳插入引用（FR-2.9.10 P3 批次）

> 2026-09-29 立项（分支 `feat/flow-reference-drag`）。FR-2.9.10 心流引用与速览增强的第三批——P1 / P2 见 [2026-09-25_flow-reference-enhance/](../2026-09-25_flow-reference-enhance/flow-reference-enhance.md)（其 D4 暂缓项由此转正）。动机：既有引用插入动线全是键盘系（`[[` 补全要打字、Alt+I 面板是键盘化目录树、斜杠 `/引入`），**惯用鼠标的用户**缺少「看到 → 拖过来」的直接动线。四项范围决策（D1–D4）当日与用户拍板。

## 需求

### FR-2.9.10（P3）拖曳插入引用

- **四源可拖**（拖起即携带笔记引用载荷，自定义 dataTransfer 类型）：
  1. 侧栏笔记库文件树的**笔记条目**（文件夹不可拖）；
  2. 全局搜索弹窗的**结果条目**（含草稿与跨库结果）；
  3. 反向链接面板**条目**（拖出 = 引用来源笔记）；
  4. 快速引用面板（Alt+I）的**笔记行与草稿行**（目录行 / 分组标题不可拖）。
- **释放点插入**：拖入编辑器松手，在**释放位置**插入 `[[引用]]`（所见即所得与源码模式一致；落点在渲染块上取最近位置）；释放点无法解析时回落当前光标。插入后光标停在引用之后。
- **引入语义沿用三路**（与 Alt+I 完全一致，收敛在 `insertPreviewTarget`）：当前库直插；跨库确认后复制为当前库副本再引用（「跨库引用免确认」开关生效）；草稿确认后复制转正再引用（原稿保留）。
- **插入格式（D2 口径）**：引用目标在当前库内叶子名**无重名** → 插 `[[笔记名]]`；**有重名**（大小写不敏感）→ 插 `[[完整路径]]`（当前笔记是草稿时不消歧、保持路径形式——草稿不进双链索引，转正时再定归宿）。
- **遮罩让行与弹窗隐藏**：从模态弹窗（搜索 / Alt+I）发起拖曳时，遮罩放行且**弹窗整体隐藏**（不遮挡编辑器落点；拖曳取消即恢复）。心流模式浮层侧栏（Alt+B）同样可用，浮层 backdrop 拖曳期间一并让行。
- **插入即关（D6，2026-09-30 用户反馈）**：从弹窗拖入**插入成功后默认关闭来源弹窗**（与键盘 Enter 插入即关的动线统一，单插主场景零负担）；**按住 Alt 拖入 = 插入后保留弹窗**（连续插入场景）；**取消拖曳不关闭**（无插入无副作用）。键盘动线对齐：搜索预览态 Alt+Enter 二段插入成功后同样关闭搜索弹窗（连续查找重开即可，v0.9.0 起开屏会清空查询与结果，需重输查询）。
- **与图片拖入共存**：OS 文件拖入仍走附件管线（回归不变）；笔记引用载荷不触发附件管线。
- 面板 / 弹窗的 Esc 关闭、点击行为、键盘动线全部零变化（不动模态结构）。

## 验收标准

1. 从侧栏树拖一条笔记到编辑器**段中间**松手：引用插在释放处（非光标原位置），点击可跳转；所见即所得与源码模式一致。
2. 搜索弹窗出结果后拖一条到编辑器：遮罩放行、释放点插入成功；**松手后搜索弹窗仍开着**，Esc 关闭行为不变。
3. Alt+I 面板笔记行 / 草稿行可拖（目录行 / 分组标题不可拖）；反向链接面板条目拖出后面板保持打开。
4. 跨库笔记拖入：弹确认框 → 确认后插入副本引用（免确认开关开启时免弹窗）；草稿拖入：确认后复制转正、原稿保留——与 Alt+I 同语义同文案。
5. 当前库无重名笔记拖入插 `[[名字]]`，重名插 `[[路径]]`；草稿内引用不消歧。
6. 拖图片文件进编辑器仍存附件目录（回归不变）；拖笔记条目不触发附件管线、不产生双插。
7. 心流下 Alt+B 呼出浮层侧栏拖曳可用；Esc 分级链、弹窗焦点管理零回归。
8. 单测覆盖载荷序列化 / 解析（含非法 JSON 容错）、遮罩让行与恢复、插入位置参数的两态括号一致性；CDP 隔离实例冒烟覆盖「拖起 → 遮罩让行 → 释放点插入 → 弹窗保持」全动线。

## 决策记录

- **D1 源范围 = 文档原列三源 + 快速引用面板**（2026-09-29 用户拍板）：快速引用面板同案纳入（同为遮罩让行方案覆盖，树 + 草稿分组一次齐活）；自定义 dataTransfer 类型做成通用形态，将来加源零成本。常用 / 收藏 / 草稿**卡片**在网格视图下编辑器不在屏上（主区网格与编辑视图互斥），拖不到，天然排除。
- **D2 遮罩方案 = 拖起时让行**（用户拍板）：`pointer-events` 让行 + dragend 恢复，不动弹窗模态结构——Esc 分级 / 焦点管理 / z 序零影响；「搜索弹窗改非模态」为过度设计（v0.9.0 D3→变更的先例已证明遮罩问题可用局部手段绕过）。
- **D3 插入位置 = 释放点**（用户拍板）：拖到哪插到哪，是拖曳相对「复制 + 粘贴」的核心价值；落点解析失败回落光标。
- **D4 跨库 / 草稿 = 沿用确认复制**（用户拍板）：不因拖曳免确认（防误拖），确认框文案与 Alt+I 完全一致；免确认开关照常生效。
- **D5 插入形式统一走 FR-2.9.10 P2 的 D2 消歧**（无重名插名 / 重名插路径，见上方需求）：拖曳对齐 `[[` 补全的插入口径；Alt+I 面板当前恒插路径形式，本批不改（后续可统一）。
- **D6 插入即关为默认、Alt 拖入保留**（2026-09-30 用户反馈拍板）：用户实测「只插一条还要手动 Esc」的摩擦 → 反转默认（普通拖入 / 键盘二段插入成功即关）；连续插入走 Alt 修饰（Alt 与本应用「插入」语义一致：Alt+Enter / Alt+I）。右键拖动不可行（HTML5 拖拽仅主键可发起，自研拖拽成本高且失去原生语义）。取消拖曳永不关（无副作用原则）。
