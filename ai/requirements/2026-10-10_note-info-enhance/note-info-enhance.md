# 笔记「信息」弹窗内容增强（FR-2.6.6 扩展）

> 2026-10-10 立项，自 [建议存档](../../suggest/note-info-enhance.md) 迁入。用户确认：P0 + P1 全做；决策点 D1–D3 按推荐方案，D4（被引用数）进本期。

## 背景

「信息」菜单项（FR-2.6.6，v0.4.0）目前只有创建时间 / 最后修改两行纯文本（`ElMessageBox.alert`）。侧栏树行与网格卡片两个入口共用此实现。原设计「不显示额外信息（YAGNI）」的前提是只有时间一个需求；现在标签、Git 同步状态等信息维度对日常使用有真实价值（尤其外部笔记库普及后，「这篇笔记在哪个库、同步了没有」是高频疑问），扩展属于重新评估。

## 功能需求

「信息」弹窗由两行纯文本升级为**分组信息卡**（只读），新增以下内容：

### P0

1. **标签区**：当前笔记的 frontmatter 标签，以胶囊呈现（颜色与标签定义一致）；**胶囊可点击** → 按该标签筛选笔记（与侧栏标签行同一筛选管线、支持并入既有多标签筛选）并关闭弹窗。无标签显示「—」。
2. **所属笔记库**：库名 + 「外部」标记（仅外部库显示）。
3. **Git 关联状态区**（仅库已关联 GitHub 时显示，未关联整区隐藏）：
   - 仓库名 `owner/repo`（悬停显示完整远程 URL）、分支名；
   - 领先 / 落后提交数（`↑n ↓m`，均为 0 时不显示）；
   - 工作区有未提交变更时显示「● 有未提交变更」，否则显示「干净」。
   - 数据读侧栏已缓存的 git 状态；该库从未刷新过时后台拉取一次，到达后原地补显（不阻塞弹窗打开）。

### P1

4. **大小 · 行数 · 字符数**：随创建 / 修改时间一并在主进程 `stat` + 读文件统计。
5. **库内相对路径** + 复制按钮（点击复制**绝对路径**，toast 提示）。
6. **被引用数**：被多少篇**不同**笔记引用（按唯一来源笔记去重，与反向链接面板徽标同口径；异步加载，打开不等待；显示「N 篇笔记」/「无」）。

## 验收标准

- 侧栏树行与网格卡片（库内容区 / 常用 / 收藏 / 分享）的「信息」均打开新弹窗，内容一致；
- 标签胶囊颜色与标签定义一致，点击后主区域切到对应标签筛选网格，弹窗关闭；
- 已关联库显示 Git 区且数据与侧栏 / 设置页一致；外部库（自动识别远程）同样显示；未关联库不显示 Git 区；
- 复制路径粘贴出的绝对路径能定位到磁盘文件；
- 深浅色主题下均正常（全部走 CSS 变量）；
- 打开弹窗不因 git / 反向链接查询而卡顿（同步数据先渲染）。

## 不做的事

- **文件夹「信息」**：维持 2026-09-13 决策（mtime 不递归更新，显示会误导）；
- **弹窗内编辑**：信息弹窗只读；标签增删走既有「标签…」菜单项；
- **写作字数（词数口径）**：中英混排口径未定，且与统计类插件分工待明确（P2，本期不做）；
- **本文件最近提交时间 / 作者**：按文件跑 `git log` 单次秒级（Windows 更慢），价值不匹配（P2）；
- **草稿**：草稿卡片现状即无「信息」入口，不涉及。
