## 需求背景

`Ctrl+N` 新建笔记当前直接在工作区创建文件——想记录的东西还没想好放哪，就要先选库 / 选目录，打断思路。用户希望：**临时想记 / 快速记录的东西先随便写**，它不一定最终会进入自己的持久笔记；保存时才给它们「转正」的机会（进入会被 Git 同步的正式笔记库）。

## 需求

### FR-2.3.9 草稿笔记

- **创建**：编辑视图内 `Ctrl+N` 创建一篇**草稿**——真实文件，但写入应用数据目录（`userData/scratch/`），**不写入用户的笔记库**，不进入搜索 / 双链与反向链接索引 / 标签索引 / Git 同步体系（草稿是独立空间，这是特性而非缺陷）；当前草稿为空时再按 `Ctrl+N` 复用该草稿（不生成空文件）；新草稿自动命名（速记 MMDD-HHmm，重名追加序号）。
- **自动保存**：草稿与常规笔记同样享受 1s 防抖自动保存（写入草稿文件）——任何时刻（含崩溃）内容都有磁盘副本，不存在「未落盘丢失」。
- **侧栏「草稿」菜单**：左侧栏新增「草稿」入口（草稿存在时显示），列出全部草稿（点击打开、⋮ 永久删除——红色确认，符合「临时」语义）。
- **转正**：草稿通过 `Ctrl+S` / 保存按钮 / 侧栏 ⋮「转正为笔记」进入转正流程——选择目标库与目录并命名后，草稿文件移入笔记库，成为参与 Git 同步的正式笔记；编辑器无缝切换到正式路径。草稿内引用的**图片附件随迁**（复制进目标库附件目录并改写引用路径）。
- **贴图**：草稿内可正常粘贴 / 拖入图片，存入草稿自有附件目录（随转正迁移）。
- **编辑能力**：所见即所得 / 源码、`[[` 补全（可引用正式笔记）、斜杠命令等编辑能力照常可用；心流模式下 `Ctrl+N` 草稿同样可用。

## 验收标准

1. `Ctrl+N` 产生新草稿并自动聚焦；空草稿复用；自动保存到 `userData/scratch/`（磁盘可见文件）。
2. 杀进程重开：草稿内容不丢，侧栏「草稿」菜单可列出并重新打开。
3. 全局搜索、双链反向链接、标签索引、自动同步均不含草稿。
4. 草稿内贴图正常显示；转正后图片在目标库正常显示、引用路径正确。
5. 转正后：目标库出现同名笔记、草稿从 scratch 移除、Git 变更可见（有远端则同步上送）、常用 / 搜索可检索到正式笔记。
6. 删除草稿有红色确认且为永久删除。
