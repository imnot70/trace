# 心流快速引用面板（FR-2.9.12）

> 2026-09-29 立项，自 [建议存档 flow-quick-ref-picker](../../suggest/flow-quick-ref-picker.md) 迁入（用户拍板按方案 A 实施）。
> 分支 `feat/flow-quick-ref-picker`。设计文档：[flow-quick-ref-picker_design.md](flow-quick-ref-picker_design.md)。

## 背景与问题

心流模式（隐藏侧栏与顶栏）下把其他笔记引入当前写作，现有两条动线都要求「先知道目标」：

| 动线 | 入口 | 适用 |
| --- | --- | --- |
| `[[` 扁平补全（FR-2.9.10） | 编辑器输入 `[[` + 名字片段 | 记得名字 |
| 搜索弹窗（FR-2.9.11） | Double-Shift | 记得关键词 |

**记不清名字、想按目录结构翻一翻**时没有入口。心流下 `Alt+B` 虽可呼出浮层侧栏，但呼出的是完整侧栏（常用 / 收藏 / 标签 / 回收站俱全）、点击节点语义是「打开笔记」（切走丢上下文）且纯鼠标导向——不适合作引用引入。

## 需求

### FR-2.9.12 快速引用面板

提供呼出式「插入引用」面板：当前库目录树（文件夹 → 笔记两级层级）+ 草稿分组，键盘优先动线，选中即把该笔记以 `[[引用]]` 形式插入编辑器光标处，**不切换当前编辑的笔记**：

- **入口（双通道，同语义）**：`Alt+I`（编辑视图内生效，心流 / 专注可用）；斜杠命令 `/引入`（FR-2.4.22 体系）。快捷键速查表登记；
- **面板形态**：模态弹窗（与搜索弹窗同构）；顶部过滤输入框（可不填，浏览为主）——输入非空时切换为扁平模糊列表（与 `[[` 补全同一匹配实现），清空恢复树形；树区为「当前库根 → 文件夹 → 笔记」层级，**草稿单独分组**置于库树之后（展示草稿名与相对时间）；
- **键盘动线**：`↑` / `↓` 移动高亮（跨文件夹时自动展开经过；悬浮预览开着时预览内容自动跟随）、`→` / `←` 展开 / 收起文件夹、`Enter` 引入、`Alt+Enter` 两段语义（与 `[[` 补全预览态一致，2026-09-29 用户反馈定案）——预览未开时以悬浮预览查看（**面板保持打开**——FR-2.9.10 ③ 搜索弹窗同款：预览内容随选中项自动跟随，可连续换目标预览），**预览开着再按 = 把当前选中笔记插入为引用**；`Esc` 分级消费：先关预览并回焦过滤框，再按才关面板；`Esc` 关闭（模态归模态，不误退心流——同搜索弹窗的分级语义）；
- **引入语义（按目标三分，全部复用既有管线）**：
  1. **当前库笔记** → 光标处插入 `[[相对路径]]`；光标处于未闭合的 `[[` 上下文时按补全落引用同款规则接续（不产生双括号，见设计 §4）；
  2. **其他库笔记** → 走跨库引用确认复制（FR-2.9.11：确认框 → 复制进当前库 → 插入引用；免确认开关生效）；
  3. **草稿** → 与跨库同路径，确认文案特化为「草稿将复制为当前库正式笔记后引用」（草稿不在双链索引，直接引用会断链——见 D3）；
- **呼出落位**：打开时自动展开并高亮当前笔记所在文件夹（省一次翻找）；
- **心流适配**：面板遮罩避让 WCO 系统三键（复用 v0.13.0 的 `env(titlebar-area-height)` 全局规则，无新增 CSS）；呼出 / 收回不触发打字机重锚。

### 非目标

- 不做拖曳生成引用（FR-2.9.10 P3 备忘项，与本需求互补）；
- 不做一次多选 / 批量引入；
- 全库树（跨库节点直接在树中浏览）列二期，一期库范围 = 当前库 + 草稿（D4）。

## 决策记录

| # | 决策 | 拍板 | 说明 |
| --- | --- | --- | --- |
| D1 | 呼出键位 | **`Alt+I`**（Insert 语义）+ `/引入` | 随方案 A 采纳倾向项；Alt+I 全局空闲（已核查），Alt 系已占用于视图 / 心流 / 侧栏 / 预览 / 打字机 / Vim；`Ctrl+P` 因 Electron 打印语义存疑不取 |
| D2 | 面板模态性与 Esc 归属 | **el-dialog 模态**（搜索弹窗同构） | 走既有 `hasModalOpen()` 让位链：Esc 先关面板、不误退心流（与搜索 / 命名 / 移动弹窗同一分级语义），不新增链级 |
| D3 | 草稿引入语义 | **确认后复制草稿为当前库正式笔记再引用** | 草稿在伪库不进双链索引，直接 `[[草稿名]]` 必然断链；「提示先转正」动线断裂；确认复制产物可同步，与跨库语义一致 |
| D4 | 库范围 | 一期：**当前库 + 草稿**；二期：全库树 | 全库树节点量大且引入必走确认复制，先验证动线再扩 |
| D5 | 呼出落位 | **自动展开并高亮当前笔记所在文件夹** | 省 `[[` 补全 / 搜索之外的高频翻找成本 |

## 验收标准

1. 心流模式下 `Alt+I` 呼出面板，显示当前库目录树（文件夹可展开收起）与草稿分组；当前笔记所在文件夹默认展开高亮；
2. 过滤框输入关键词后切扁平模糊列表（含路径消歧），清空恢复树形；
3. `Enter` 引入当前库笔记：光标处出现 `[[路径]]`，当前笔记不切换；光标在 `[[` 后时接续不产生双括号（裸 `[[` 前缀与已闭合两种状态都验证）；
4. 引入其他库笔记弹确认框，确认后引用指向复制产物；免确认开关开启时直接插入；
5. 引入草稿弹特化确认文案，确认后草稿复制为当前库正式笔记并插入引用；
6. `Alt+Enter` 以悬浮预览打开所选笔记且**面板保持打开**（2026-09-29 用户反馈修订：原「关面板后预览」导致连续预览需反复 Alt+I，改为与搜索弹窗同款——预览随 ↑/↓ 选中自动跟随）；**预览开着再按 `Alt+Enter` = 插入当前选中笔记的引用**（2026-09-29 用户反馈二次定案，与 `[[` 补全预览态一致）；`Esc` 先关预览并回焦过滤框，再按 `Esc` 关面板；关面板后心流仍在（再按 `Esc` 才走既有回退链）；
7. 非心流（常规 / 专注）编辑视图 `Alt+I` 同样可用；`/引入` 斜杠命令与 `Alt+I` 行为一致；
8. WCO（Windows）下面板避让系统三键；既有全量单测绿，新增单测全绿。
