# 打字机留白生命周期重设计（含心流内三态循环、预览对齐）

> 2026-09-27 立项。来源：index 第二节「打字机留白的两个收尾缺陷」（2026-09-25 用户实测，前一次
> `fix/typewriter-cleanup` 分支方案已放弃）+ 同问题域的「打字机留白导致常规预览错位（暂不修）」。
> 方案经用户拍板（2026-09-27，三问三答）：① 技术方案选**声明式承载**；② 心流内 `Alt+T` 选
> **三态循环、关生效**；③ 预览错位**一起修**。

## 1. 背景与问题

### 1.1 缺陷①：打字机设为「关闭」后仍保留上次的高位 / 低位观感

两个候选根因（本次调研确认，分别覆盖）：

- **语义盲区（静态可证）**：心流内打字机形态走 `effectiveTypewriterMode` 推导
  （`lib/flow.ts`），「关闭」被**强制映射为「低位」**——在心流内按 `Alt+T` 切到「关」，设置
  确实写入了「关」，但生效形态仍是低位：**「关」在心流内不可表达**，观感与设置直接矛盾。
- **僵尸写回（真机时序）**：留白由插件实例以内联样式写在 `.cm-content` 上，清理完全依赖
  `destroy()` 里的两行 JS；本机隔离实例无法复现，真机才触发（时序型缺陷温床）。

### 1.2 缺陷②：退出心流后顶部留白没有被去掉

同 1.1 的僵尸写回路径。静态审查发现两个具体漏洞：

- `destroy()` **漏删 `scrollDOM` 上的 scroll 监听**（模式每次切换泄漏一个闭包）；
- `ResizeObserver` 回调**不看 entries 是否为空一律执行**（写回留白 + 调度锚定）。

### 1.3 遗留项：打字机留白导致常规预览错位（原「暂不修」）

打字机开启时 `.cm-content` 顶部有 paddingTop 留白而预览没有，行级同步的坐标映射在**文档头部
附近**（编辑器视口顶边落在留白区内时）出现偏移：留白区在映射函数里都被折算成第 1 行、比例钳到
0，预览被推到块顶而非同坐标。中段映射与留白无关（两侧各自坐标空间自洽），文档尾部同理受益于
等量底部留白。

## 2. 需求（D1–D3）

### D1 留白清理不依赖 JS 时序（根治缺陷②）

- 留白的**承载层从内联样式改为扩展自带 theme + CSS 变量**：`.cm-content` 的
  `padding-top: var(--tw-pad-top, 0px)` 由打字机扩展的 theme 提供；切到「关」时扩展随
  compartment 摘除，theme 规则被 CM **自动移除**，padding 无条件回到基线——清理路径不再存在于
  JS 中，「忘了清 / 被写回」在机制上不可能发生。
- CSS 变量的**唯一写者是 EditorView（Vue 层）**：按当前形态的比例 × 编辑器滚动区高度计算，
  绑定在编辑卡 `:style`（与 `--flow-measure` 同一挂点），ResizeObserver 跟随高度变化。
- 插件瘦身为**纯锚定**：不再写任何样式；`destroy()` 无需清理。迟到回调只可能触发滚动，
  以 `destroyed` 标志守卫（本次 flag 只护滚动，不再参与留白清理，与上次失败分支职责不同）。
- 顺带修复：`destroy()` 补删 scroll 监听；RO 回调 entries 为空早退。

### D2 心流内 `Alt+T` 三态循环、「关」生效（根治缺陷①的语义盲区）

- **进入心流时**：设置是「关」仍自动低位（原设计不变）；进入后打字机形态记录为**会话态**
  （`flowTypewriter`），不再每次从设置推导。
- **心流内 `Alt+T`**：在 高位 ↔ 低位 ↔ 关 之间三态循环，「关」真实生效（光标不锚定、留白
  清掉）。显式动作被尊重，设置与观感一致。
- **退出心流后**：按设置值走（心流内的切换已同步写回设置，退出前后一致）；非心流下 `Alt+T`
  保持现有「关 ↔ 上次形态」二态切换不变。
- 设置页在心流内改打字机设置同样写会话态（`updateSettings` 收口同步）。

### D3 预览同比例留白 + 头部区 1:1 同步（修复遗留项）

- 打字机开启时，分栏预览与悬浮预览（当前笔记、参与同步的）加**同值上下留白**，两容器可视
  内容起点一致，文档尾部也能等距滚动；补全预览（展示别的笔记、不参与同步）不加。
- **头部区 1:1 同步**：编辑器视口顶边落在留白区内（`scrollTop ≤ paddingTop`）时，行号映射
  失义，改按滚动坐标 1:1 直传预览（反向同理）——文档头部附近不再偏移；中段仍走行级映射。

## 3. 验收标准

1. 高位/低位 → 关（非心流，Alt+T 与设置页两入口）：留白立即清零（computed paddingTop/Bottom
   归 0），滚动行为与常规一致；快速反复切换 20 次后无残留。
2. 进心流（设置关）→ 自动低位；心流内 Alt+T 低位→关：留白清零、状态区图标反映「关」；再按
   → 高位；退出心流后打字机按设置（最后一次切换已写回）。
3. 退出心流（心流内为关）后无任何留白残留；（心流内为高位且设置高位）退出后高位留白保持，
   属预期行为。
4. 预览对齐：打字机开启时，编辑器滚到文档头部（顶边在留白区内），预览滚动位置与编辑器一致
   （坐标 1:1）；滚回中段，行级映射行为与原先一致；关闭打字机后预览无留白。
5. 全量单测 / lint / typecheck 绿；隔离实例 CDP 验证通过。

## 4. 方案要点（详见 _design.md）

- 承载层：扩展 theme + CSS 变量（D1）；变量写者唯一（EditorView）；插件纯锚定 + destroyed 守卫。
- 会话态：`flowTypewriter`（D2）；三态循环纯函数 `nextTypewriterCycle`（可单测）。
- 预览：`MarkdownPreview` 新增 padding props；同步函数头部区分流（D3）。
