# 正文内联 #标签（FR-2.6.18）

> 2026-10-12 立项（用户提案池 [标签系列](../../suggest/feature-proposals.md) 遗留项迁入，2026-09-26 标签一期/二期立项时明确「双源设计决策大，需单独立项讨论」）。三决策当日经用户拍板（D1–D3，见 [设计文档](inline-body-tags_design.md)）：**只读识别 / 聚合全包含 / 完整闭环**。

## 需求背景

标签体系（FR-2.6.7–2.6.17）以 frontmatter 为唯一事实源：打标签 / 摘标签都走打标签弹窗或所见即所得的 frontmatter 胶囊，正文里手写的 `#标签` 只是普通文字。用户希望 Obsidian 式的「写到正文即打标签」体验，但完整双真源（正文编辑即增删标签）涉及删除语义模糊、去重与改名双向扫写等大决策。本项目取折中形态：**正文标签只读识别**——识别、高亮、计数、筛选全部生效，但增删标签的管理入口保持不变（正文是「用」，frontmatter 是「管」）。

## 需求

### FR-2.6.18 正文内联 #标签识别

**识别规则**（正则单一定义源 `shared/noteTags.ts`）：

- 形态：`#` 后接 1–64 个「字母 / 数字 / 下划线 / 连字符」（Unicode 类，中英文皆可），尾部 `-` / `_` 截除；大小写不敏感归一（与既有标签口径一致）；
- 排除：frontmatter 区、围栏代码块、行内码、前一字符为「字母 / 数字 / 下划线 / `#` / `&` / `/`」的位置（排除 `C#5`、`##标题`、HTML 实体 `&#123;`、URL 片段 `x.com/#anchor`）；
- 行首 `# `（ATX 标题，井号后有空格）天然不匹配；行首 `#标题`（无空格）按正文标签识别——与 CommonMark 的标题定义一致，不是标题。

**渲染与交互**：

1. **预览**：正文 `#标签` 渲染为胶囊样式（`md-inline-tag`，颜色走标签定义色），单击跳转该标签的筛选视图；
2. **所见即所得**：源码态 `#标签` 以同款样式高亮（mark 装饰，不改 DOM 结构——组词安全），**Ctrl/Cmd+单击**跳转该标签的筛选视图（与双链 Ctrl+Click 打开同分流，普通单击保持落光标编辑语义）；
3. **跳转筛选**：与笔记信息弹窗胶囊（FR-2.6.6 扩展）同逻辑——进入 / 切换标签网格筛选（多选组合 FR-2.6.13 口径）；正文标签尚无定义时自动创建定义（自动配色，与「外部工具写的标签可见可用」同哲学）。

**聚合口径（真源并集）**：

4. **侧栏标签计数**（FR-2.6.15/16 口径）：一篇笔记的标签 = frontmatter tags ∪ 正文 `#标签`（篇内去重，大小写不敏感）；
5. **标签筛选**（`tag:byTag` / `tag:byTags` AND·OR）：同一并集口径；
6. **搜索标签维度**（FR-2.9.11）：索引项标签 = 并集，标签下拉聚合与筛选自动跟随；
7. **定义自动注册**：正文标签在聚合扫描时自动注册定义（自动配色）——侧栏可见、可管理、可改色。

**管理操作联动（闭环正确性）**：

8. **改名**（FR-2.6.15 管线）：全库扫写正文 `#旧名` → `#新名`（识别规则同上；不触碰 frontmatter 区 / 代码 / 行内码）——否则正文残留的 `#旧名` 会在下次聚合时把已改名的标签以僵尸形态自动注册回来；
9. **合并**：同上，正文 `#源名` → `#目标名`；
10. **删除**：全库移除正文 `#标签`（与「从全部关联笔记移除」的既有语义对齐——标签不再存在于任何位置；识别到什么删什么，误识别场景由识别规则边界约束）；
11. **管理入口不变**：打标签弹窗（FR-2.6.12）与所见即所得 frontmatter 胶囊（FR-2.6.17）仍只读写 frontmatter——正文标签不提供任何写入口。

### 非目标

- 双真源（正文编辑即增删标签）——D1 已拍板不做；
- 打标签弹窗候选列表含正文标签补全——后续按需；
- 笔记「信息」弹窗标签胶囊改并集口径——维持 frontmatter 管理口径（筛选本身已是并集）。

## 验收标准

1. 正文写 `#旅行` 后（无 frontmatter 标签），侧栏出现「旅行」且计数正确；AND / OR 组合筛选能命中该笔记；搜索标签下拉含「旅行」；
2. 预览中 `#旅行` 显示为胶囊样式，单击进入筛选；所见即所得中高亮，Ctrl+单击进入筛选，普通单击落光标可编辑；
3. 行内码 `` `#旅行` ``、代码块、frontmatter、`C#5`、`x.com/#a` 均不被识别；
4. 改名 / 合并后正文 `#旧名` 同步改写；删除后正文 `#标签` 被移除且不复活；
5. 既有标签单测全绿，新增识别 / 聚合 / 改写单测覆盖上述边界。
