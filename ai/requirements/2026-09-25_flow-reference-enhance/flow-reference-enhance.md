# 心流引用与速览增强（FR-2.9.10）

> 2026-09-25 立项。背景：v0.8.3 上线的「心流快速查阅」（`[[` 补全 + Alt+Enter 悬浮预览）真机使用后暴露三点不足（用户实测反馈）：① Alt+Enter 预览后按 Esc 想退出预览，补全面板却连着一起关了；② `[[` 补全必须知道完整路径才能逐级导航，记错层级要退出来重来；③ 搜索结果没有键盘上下选择支持，也因此无法做 Alt+Enter 预览。与用户确认分三批（P1 / P2 / P3），P3 拖曳暂缓。

## 需求

### FR-2.9.10 心流引用与速览增强

- **Esc 分级消费（P1）**：应用级 Esc 回退（悬浮预览 → 设置 → 心流）每一步消费按键后，事件不得继续到达编辑器键位——关悬浮预览时补全面板保持打开，再按一次 Esc 才收起补全。
- **`[[` 扁平模糊匹配（P2）**：补全查询不含 `/` 时不再逐级导航，改为**全库笔记扁平匹配**——输入名字片段即列出全部命中笔记（detail 显示所在目录用于消歧），方向键选择；含 `/` 时保留现有逐级行为。同名笔记（库内大小写不敏感重名）插入完整路径，无重名插入笔记名（双链按名解析）。
- **搜索结果键盘导航与预览（P2）**：全局搜索框支持 ↑ / ↓ 在结果间移动高亮（循环，自动滚入视野）、Enter 打开选中项、Alt+Enter 以悬浮预览查看选中项（复用 v0.8.3 悬浮预览机制）；鼠标悬停同步高亮。

## 验收标准

1. 心流下 `[[` → Alt+Enter 预览 → 按 Esc：悬浮预览关闭、补全面板**保持打开**；再按 Esc 收起补全；再按 Esc 退出心流（三级回退逐级消费）。
2. 输入 `[[首页`（不输路径）：列出全库所有名字含「首页」的笔记；只记得部分名字（如 `[[笔记`）同样能命中；detail 显示目录。
3. 输入 `[[dir_02/`（含 `/`）：行为与 v0.8.3 一致（该目录下的子文件夹与笔记）。
4. Ctrl+F 搜索出结果后：↓ / ↑ 移动高亮且列表滚动跟随；Enter 打开选中笔记；Alt+Enter 关闭搜索框并以悬浮预览查看；鼠标点击行为不变。
5. 单测覆盖扁平匹配的排序 / 重名消歧 / 排除自身 / 上限截断。

## 决策记录

- **D1** 扁平模式只列笔记、不列文件夹：文件夹是逐级导航的辅助，全局笔记列表（上限 30 条）已覆盖「快速找笔记」诉求。
- **D2** 重名消歧方向：插入侧优先笔记名（预览点击同名有消歧弹层兜底），仅库内真重名时插入完整路径保证解析唯一。
- **D3** 搜索预览时**关闭搜索框**：搜索框是模态对话框，遮罩会压住悬浮预览的 z 序；Ctrl+F 可立即重开。将来搜索框改非模态时可再优化为并存。
- **D4** P3 拖曳（搜索结果 / 文件树 / 反向链接列表拖入编辑器生成引用）暂缓：主要成本在搜索框模态改造，待 P2 试用后再评估是否需要。
