# 右键上下文菜单（FR-2.4.28）

> 2026-09-30 立项，自 [建议存档 context-menu](../../suggest/context-menu.md) 拍板迁入（**P1 + P2 实施，P3 轮盘放弃**——分层上下文下轮盘反而慢且有干扰，存档保留结论）。
> 分支 `feat/context-menu`。

## 背景

全应用 0 处 `contextmenu` 处理：编辑器内右键弹 **Chromium 原生菜单**（打包后带「检查」项，全应用最出戏的 UI 残留）；侧栏 / 网格 / 标签 / 回收站的动作全靠精准悬停 `⋮` 小按钮。右键是唯一空置的输入通道。

## 需求

### FR-2.4.28 编辑器右键菜单（P1）

编辑器内右键弹出应用菜单（preventDefault 原生菜单），按光标上下文分节呈现：

| 上下文 | 菜单项 |
| --- | --- |
| 任意 | **剪切 / 复制 / 粘贴**（有选中才亮剪切 / 复制；粘贴走主进程 `webContents.paste()`，归一化 FR-2.4.25 自动生效） |
| 有选中文字 | 加粗 / 斜体 / 删除线 / 行内码 / **转为双链**（`[[选中]]`）/ 复制选中 |
| 光标在双链上 | 打开笔记 / 复制 `[[引用]]` 文本 |
| 光标在链接上 | 打开外部链接 / 复制链接地址 |
| 光标在图片上 | 在附件目录中显示 / 复制图片路径 |

- **上下文判定**：右键位置先 `posAtCoords` 定位（把光标挪到右键点，与桌面编辑器惯例一致），再查该位置的语法节点 / 选区状态决定分节（±1 容差——`posAtCoords` 对原子 widget 返回区间外位置，09-30 教训）；
- 选区与光标上下文**同时成立时都显示**（先选区节，后位置节）；
- 输入框（设置页 / 各过滤框）**保留原生菜单**（系统拼写 / 剪贴板能力），不替换——非决策项，桌面惯例。

### FR-2.4.29 树 / 网格 / 标签 / 回收站右键（P2）

右键各表面 = 打开该对象既有的 ⋮ 菜单（同一份菜单项定义，**动作永不分叉**）：

| 表面 | 菜单内容 |
| --- | --- |
| 侧栏树（库 / 文件夹 / 笔记） | 镜像各自 ⋮（新建 / 导出 / 分享 / 移动 / 重命名 / 信息 / 标签 / Git / 删除红） |
| 网格卡片（库 / 文件夹 / 笔记 / 草稿 / 分享） | 镜像卡片 ⋮ |
| 标签行 | 重命名 / 改色 / 合并到…（FR-2.6.15，2026-10-09 起随 `tagRowItems` 单一定义源自动获得）/ 删除 |
| 回收站条目 | 还原 / 彻底删除（现为两个按钮，右键菜单化并保留按钮） |

## 决策记录

| # | 决策 | 拍板 | 说明 |
| --- | --- | --- | --- |
| D1 | 轮盘菜单 | **放弃**（用户拍板） | 分层上下文下轮盘反而慢且有干扰；结论存档于 suggest |
| D2 | 剪贴板管线 | **主进程 `webContents.paste()` / `cut()` / `copy()`**（每次调用注入，无持久状态） | dispatch 文本会绕过 FR-2.4.25 DOM paste 归一化；原生路径事件完整保留 |
| D3 | 菜单实现 | **自绘浮层**（Vue 组件，Teleport body + fixed 定位） | EP dropdown 为 trigger 驱动，程序化「在任意坐标打开」不适配；自绘项渲染与快捷键提示可控 |
| D4 | P2 镜像方式 | **菜单项定义抽取共享**（items 数组 → dropdown 与 contextmenu 同源渲染） | 动作永不分叉 |
| D5 | 心流 / 专注下的可用性 | 可用（顶栏隐藏不影响） | 右键不依赖顶栏 |
| D6 | 右键与选区的关系 | **右键点在选区内 → 保留选区直接弹菜单；选区外 → 光标挪到指针处再弹** | 桌面编辑器惯例 + 保护用户已选内容（2026-09-30 用户确认） |
| D7 | 树 / 卡片菜单差异项（如「在侧栏中定位」） | 右键取**并集**（全量动作），⋮ 菜单维持现状 | 右键定位是「最全的那份」；动作同源不会失效（2026-09-30 用户确认） |
| D8 | 剪贴板项的快捷键 hint | 照常标注 Ctrl+X/C/V，不为 Vim 开启做区分 | vim 用户自知状态，不加条件逻辑（2026-09-30 用户确认） |
| D9 | P2 抽取范围 | **完整抽取**：四组件 dropdown 模板改共享定义 v-for 渲染 | 动作永不分叉，接受较大 diff（2026-09-30 用户确认） |

## 验收标准

1. 编辑器右键：原生菜单不再出现；无选中显示剪贴板节 + 位置节；选中文字时显示格式节（五项）+ 复制选中；
2. 选中「某词」→ 右键「转为双链」→ 文档出现 `[[某词]]`；光标在 `[[引用]]` 上右键可打开 / 复制；
3. 右键粘贴含 NBSP 文本 → 落盘内容已归一化（FR-2.4.25 生效）；右键剪切 / 复制对系统剪贴板生效；
4. 树 / 卡片 / 标签 / 回收站右键弹出的菜单项与对应 ⋮ 菜单**逐项一致**，动作结果一致；
5. Esc / 点击外部 / 执行动作后菜单关闭；菜单不遮挡右键点（近边缘自动翻转）；
6. 心流 / 专注下全部可用；既有全量单测绿 + 新增单测绿；CDP 冒烟覆盖编辑器三上下文与树右键。
