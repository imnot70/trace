# 任务标记容忍与不可见字符治理（FR-2.4.24）

> 2026-09-29 立项（自 [index 待办 #11](../index.md) 转正，诊断见 [tech_product-interaction 教训 8](../../tech/tech_product-interaction.md)）。
> 分支 `feat/task-marker-tolerance`。设计文档：[task-marker-tolerance_design.md](task-marker-tolerance_design.md)。

## 背景

用户笔记的任务行混入**不换行空格（NBSP, U+00A0）**（网页 / 聊天工具粘贴待办清单的常见污染）后，「任务列表任何模式都不渲染」：markdown-it（预览 / 导出）与 lezer（所见即所得）两条解析管线都只认 ASCII 空格，任务识别同时失效；雪上加霜的是无 URL 的 `[x]` 被语法树解析为引用式 Link 节点、被误涂链接蓝（**该误涂已随 v0.13.0 修复**，不在本需求范围）。

两条管线的失效面**不一样宽**（本需求设计的事实基础）：

| 污染位置 | 例子（⍽ = NBSP） | markdown-it（`trace_task_lists` 规则 `^\[([ xX])\]\s+`） | lezer（TaskParser 守卫 `/^\[[ xX]\][ \t]/`，1.7.2 实测） |
| --- | --- | --- | --- |
| `[x]` 与正文之间 | `- [x]⍽任务` | ✅ 能认（JS `\s` 恰好含 NBSP） | ❌ 守卫只认 ASCII 空格 / 制表符 |
| 列表标记与 `[` 之间 | `- ⍽[x] 任务` | ❌ `^\[` 不匹配 | ❌ 同样不生成 Task 节点 |
| 中括号内 | `- [⍽] 任务` | ❌ 不匹配 | ❌ 不匹配 |
| 行首（列表标记之前） | `⍽- [x] 任务` | ❌ 整行不再是列表 | ❌ 整行不再是列表 |

## 需求

### FR-2.4.24 任务标记容忍识别（读侧）

含不可见字符变体的任务行，在**预览、导出（PDF/HTML）、所见即所得**三条渲染路径中都按 GFM 任务渲染（复选框 + 勾选态），勾选点击可正常写回：

- 容忍位置：`[` 前导不可见字符（列表标记与 `[` 之间）、中括号内空白变体（视为**未勾选**）、`]` 与正文之间的不可见空白分隔符；
- **ASCII 行为零变化**：容忍只对「lezer / 既有正则本已拒绝」的不可见变体生效，正常 `- [ ] 任务` 的渲染、勾选、回落源码等一切行为不变；
- 行首污染（`⍽- [x]`，整行不再是列表）**不在解析容忍范围**（会改变块结构判定，涉面失控），由 FR-2.4.25 的两条治理路径覆盖；
- `- [x]` 行尾无分隔空白时仍不视为任务（与 GFM 及两管线既有行为一致，不借本次放宽）。

### FR-2.4.25 不可见字符治理（写侧 + 存量）

- **粘贴归一化**：编辑器粘贴纯文本时自动归一——NBSP / 窄 NBSP（U+00A0 / U+202F）替换为普通空格，零宽字符（U+200B / U+2060 / U+FEFF）删除；**U+200D ZWJ 与 U+200C ZWNJ 绝不处理**（emoji 与阿拉伯系文字的合法成分）。实际发生替换时 toast 提示「已清理 N 个不可见字符」，零替换完全静默；
- **清理本文命令**：「清理不可见字符」入口（顶栏按钮 + 斜杠命令 `/清理字符`）——扫描当前笔记，弹确认框列出将替换的字符种类与处数，确认后单事务写回（既有外部修改 hash 保护自动生效）；未发现时提示「未发现不可见字符」。服务于两类场景：存量受染笔记、发布 Gist 前的预清理（GitHub 渲染同样不认 NBSP 任务）。

### 非目标

- 不做加载 / 保存时静默归一（违反「不悄悄丢数据」——文件是唯一事实来源）；
- 不处理代码块 / 行内码内的不可见字符（粘贴归一化会波及，但字符集最小化且该场景下替换为空格无语义损失；解析容忍不涉及代码区）；
- 不处理拖放（drop）外部文本（污染入口以粘贴为主，后续有实据再扩）。

## 验收标准

1. 构造含 NBSP 的任务行（四种污染位置逐项），预览与所见即所得均渲染复选框；`[⍽]` 呈现未勾选；点击复选框勾选态正确写回且不改动行内 NBSP（最小写入）；
2. 正常 ASCII 任务行在预览 / 所见即所得 / 勾选写回上与改动前逐字节一致（回归）；
3. 粘贴含 NBSP / 零宽字符的文本后落盘内容已归一，ZWJ / ZWNJ 原样保留；零污染粘贴无 toast；
4. 清理命令对无污染笔记提示「未发现」；有污染时确认框数字正确、确认后全文字节符合预期、取消不写；
5. 既有全量单测绿；新增 matcher 矩阵 / 渲染 / 装饰 / 归一化单测全绿。
