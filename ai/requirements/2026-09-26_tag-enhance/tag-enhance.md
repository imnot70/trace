# 标签功能优化（FR-2.6.12–2.6.17）

> 2026-09-26 立项（用户提案池 [#1 / #2](../../suggest/feature-proposals.md) 迁入）。设计文档：待设计（排期见提案池「建议打包」——一期打包内联新建 + 多标签组合筛选 + 自动配色）。

## 需求背景

标签系统（FR-2.6.7–2.6.11）已具备存储 / 管理 / 筛选 / 折叠能力，真机使用中暴露若干效率短板：打标签时遇到没有的标签要跳出弹窗去侧栏新建；筛选只能单标签；新建标签必须手动选色。本需求把提案池盘点的高频优化点转为正式需求，分一期打包与后续可选两档。

## 需求

### FR-2.6.12 打标签时内联新建标签（原提案 2）

给笔记加标签时若无合适标签，直接在打标签弹窗内新建，不用回侧栏点「+」：

- 弹窗的过滤输入**无匹配时**，列表末尾显示「＋ 新建标签『{关键词}』」行，点击即创建（自动从柔和色板取色，可后改）并自动勾选到当前笔记；
- 名称校验复用 `shared/validate`（与侧栏「+」一致）；重名时提示并定位既有标签。

### FR-2.6.13 多标签组合筛选

按标签筛选网格从单标签升级为多标签组合：

- 侧栏标签区支持多选；
- 提供「满足全部（AND）/ 满足任一（OR）」切换；
- 筛选结果与既有网格 / 列表视图、排序行为兼容。

### FR-2.6.14 新建标签自动配色

新建标签时从柔和色板自动取色（可后改），省掉必选颜色步骤；侧栏「+」与内联新建（FR-2.6.12）同一色板逻辑。

### FR-2.6.15 标签合并（可选，二期）

把标签 A 的所有笔记并入标签 B：frontmatter 批量改写 + 删除标签 A，减少标签碎片化；合并前展示两侧笔记数并要求确认。

### FR-2.6.16 使用频率 / 最近使用排序（可选，二期）

侧栏标签区与打标签弹窗支持按笔记数或最近使用排序。

### FR-2.6.17 frontmatter 标签可视化编辑（可选，二期）

所见即所得模式下 frontmatter 区的 `tags` 以胶囊展示、可点选增删（装饰渲染 + 与标签系统双向同步）。

### 非目标

- **正文内联 `#标签` 识别**：不纳入本需求。frontmatter 与正文双写入口涉及写入口径 / 去重 / 迁移的双源设计大决策，需单独立项讨论（提案池原文结论）。

## 验收标准

1. 打标签弹窗输入无匹配关键词时出现内联新建行，点击后标签创建并勾选，颜色自动分配；
2. 侧栏多选标签后网格按 AND / OR 正确过滤，取消选择恢复；
3. 新建标签（侧栏 / 弹窗）无需手动选色即有可辨析颜色；
4. 既有标签管理（重命名 / 删除 / 改色）与存储迁移不回归（既有单测全绿）。

## 备注

- 工时评估（建议阶段）：一期（FR-2.6.12–14）约 1~1.5 天；二期各项 0.5~1 天 / 胶囊编辑 2 天；
- 打包建议：一期随「快速引入图片」（FR-2.5.4）凑一个高频痛点小版本。
