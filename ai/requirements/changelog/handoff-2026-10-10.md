## 七、本会话新增工具与教训

1. **Edge 无头截图在本机失效**（无输出、不报错）——用 Chrome：
   ```bash
   "C:/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --user-data-dir="$TEMP/chrome-mock" --hide-scrollbars --window-size=1760,990 --virtual-time-budget=12000 --screenshot=out.png "file:///…/index.html?scheme=ink&theme=dark&compare=0"
   ```
2. **dev 实例 CDP 驱动/截图脚本**（`TRACE_CDP=9222 npm run dev` 后用；临时文件不入库，脚本全文如下，建议接力时酌情入库 `scripts/`）：
   ```js
   // 用法：node cdp-shot.mjs <输出.png> [页面内 evaluate 的表达式]
   const list = await (await fetch('http://127.0.0.1:9222/json')).json()
   const page = list.find((t) => t.type === 'page')
   const ws = new WebSocket(page.webSocketDebuggerUrl)
   let id = 0
   const pending = new Map()
   const send = (method, params = {}) => new Promise((resolve, reject) => {
     const mid = ++id
     pending.set(mid, { resolve, reject })
     ws.send(JSON.stringify({ id: mid, method, params }))
   })
   ws.onmessage = (ev) => {
     const msg = JSON.parse(ev.data)
     if (msg.id && pending.has(msg.id)) {
       const { resolve, reject } = pending.get(msg.id)
       pending.delete(msg.id)
       msg.error ? reject(new Error(JSON.stringify(msg.error))) : resolve(msg.result)
     }
   }
   await new Promise((r, j) => { ws.onopen = r; ws.onerror = j })
   await send('Page.enable')
   const expr = process.argv[3]
   if (expr) {
     console.log('evaluate:', JSON.stringify((await send('Runtime.evaluate', { expression: expr, awaitPromise: true })).result?.value))
     await new Promise((r) => setTimeout(r, 800))
   }
   const shot = await send('Page.captureScreenshot', { format: 'png' })
   ;(await import('node:fs')).writeFileSync(process.argv[2], Buffer.from(shot.data, 'base64'))
   ws.close(); process.exit(0)
   ```
   验证未解析组件的探针：扫 `document.querySelectorAll('*')` 的 tagName 是否命中 EP 图标名小写（本轮 P2 全零）。
3. **dev 进程残留**：结束 dev 后 electron 子进程常存活并占单实例锁，重启前 `taskkill //F //IM electron.exe`；
4. **CDP `Page.captureScreenshot` 拍不到 WCO 三键区与 DWM 材质**（原生层）——标题栏 / 玻璃效果只能真机目验；
5. 合成事件点不开 `el-dropdown`（既有教训的又一实例）；`el-dialog` 关闭后 DOM 驻留——可直接读计算样式做样式断言；
6. 本机 Git Bash 的 grep 是 ugrep：`-E "a|{"` 这类含空分支的表达式会报错，写正则时避开空分支。
