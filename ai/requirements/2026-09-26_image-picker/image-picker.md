# 快速引入图片（FR-2.5.4）

> 2026-09-26 立项（用户提案池 [#7](../../suggest/feature-proposals.md) 迁入）。设计文档：待设计。工时评估（建议阶段）★~★★，0.5~1 天。

## 需求背景

图片进入笔记现有两条路：粘贴 / 拖入（FR-2.5.1，自动存附件目录并生成相对引用）。缺「从本地文件系统选择既有图片文件」的入口——截图存在磁盘上时，得先打开再复制才能粘贴，多一步。本需求补系统文件选择器入口。

## 需求

### FR-2.5.4 快速引入图片

- 工具栏「图片」按钮与快捷键 `Ctrl+Shift+I`（当前无占用）打开**系统原生文件选择器**（多选），filter 常见图片格式（png / jpg / jpeg / gif / webp / svg / bmp）；
- 选中文件复制进库附件目录（`attachmentsDir`，FR-2.5.2），按**既有附件命名规则**（时间戳前缀防重名）处理重名——命名 / 重名逻辑从粘贴管线抽成公共函数两处共用；
- 返回生成的引用名列表，编辑器光标处**批量**生成 `![](attachments/…)` 引用；
- 操作系统差异由 Electron 屏蔽（Windows / Linux 原生对话框、GTK portal）；图片**不做格式转换**（与粘贴管线一致，冷门格式兼容性由系统决定）；主进程完成选择 / 复制 / 命名全部动作，渲染端一次 IPC 调用。

## 验收标准

1. 工具栏按钮与 `Ctrl+Shift+I` 均可呼出系统选择器；多选文件后光标处按序批量插入引用；
2. 引用文件名带时间戳前缀，重名不覆盖；预览 / 所见即所得中图片正常显示（`trace-vault://` 管线复用）；
3. 取消选择无任何写入；非图片文件被 filter 排除；
4. 插入的引用与粘贴产生的引用格式完全一致（同一公共函数产出）。
