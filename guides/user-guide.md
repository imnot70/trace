# Trace 笔迹用户手册

Trace 是一款本地优先的 Markdown 笔记应用，数据以纯 Markdown 文件存储，支持 LaTeX 公式、图片粘贴、Git 云同步、主题定制与插件扩展。跨平台：Windows / macOS / Linux（Ubuntu/Debian 为主）。

---

## 1. 安装与启动

### 安装包下载

从项目 [Releases](../../releases) 页面下载对应平台的安装包：

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Ubuntu / Debian | `linux-v0.x.x-x64.deb` | `sudo dpkg -i linux-v*.deb` 或 `sudo apt install ./linux-v*.deb` |
| 其他 Linux | `linux-v0.x.x-x64.AppImage` | `chmod +x linux-v*.AppImage && ./linux-v*.AppImage`（需 FUSE，或 `--appimage-extract` 后运行） |
| Windows | `win-v0.x.x-x64.exe` | 双击安装，可选择安装目录 |
| macOS | 暂不提供安装包，请从源码构建（见下方） |

> 同步功能依赖系统 git。未安装时其余功能不受影响，关联远程仓库时会提示安装。

### 从源码构建（macOS 及开发者）

```bash
git clone <仓库地址> trace
cd trace
npm install          # 安装依赖
npm run dev          # 开发模式启动（渲染进程热更新）
```

打包：

```bash
npm run dist         # 按当前平台打包安装程序
npm run dist:deb     # 只打 Ubuntu/Debian deb 包
```

## 2. 界面说明

### 左侧栏

侧栏分为四个区域，从上到下：

- **常用**：最近打开的笔记（最多 20 条），点击标题在主区打开卡片视图
- **收藏**：已收藏的笔记，点击标题打开卡片视图
- **回收站**：点击直达回收站列表
- **笔记库**：已创建的笔记库列表，库名右侧有齿轮（设置）和 `+`（新建）按钮

回收站与笔记库之间有一条分隔线，区分上方快捷入口区与笔记库区；上方分区全部隐藏时分隔线自动隐去。

侧栏左下角：⚙️ 设置按钮；可收起为迷你导航条，点击展开。

**菜单开关**：设置 → 通用 → 侧栏菜单可分别显示 / 隐藏「常用 / 收藏 / 标签 / 断链引用 / 回收站」分区；「笔记库」始终显示。编辑卡右下角的反向链接入口由设置 → 通用 → 编辑器 →「显示反向链接」控制。

### 三栏布局

- **左侧栏**：导航
- **编辑区**（中间）：笔记源码编辑 + 工具栏
- **预览区**（右侧）：实时渲染预览

编辑卡顶栏右侧有：预览收缩按钮（隐藏/显示预览）、专注模式按钮。

## 3. 笔记库管理

### 创建笔记库

侧栏「笔记库」右侧点击 `+` → 输入名称 → 确认（可选填描述）。

### 笔记库操作

点击库名右侧齿轮按钮：

| 操作 | 说明 |
| --- | --- |
| 关联 Git 仓库 | 登录 GitHub 后可关联远程仓库同步 |
| 立即同步 | 对已关联库执行 git 同步（提交→拉取→推送） |
| 重命名 | 修改库名，需通过重名校验 |
| 删除笔记库 | 将库及其内容全部移入回收站（红色警示） |

### 网格视图

点击「笔记库」标题可在主区打开网格视图，展示所有笔记库卡片（名称 + 描述 + Git 状态）。双击库卡片可进入库内容视图。

## 4. 文件夹与笔记管理

### 创建文件夹 / 笔记

- **库行右侧 `+`**：新建文件夹 或 创建笔记
- **文件夹行 `⋮` 菜单**：新建文件夹、创建笔记、重命名、删除（红色）
- **笔记行 `⋮` 菜单**：重命名、删除（红色）、收藏

### 操作方式

- **悬浮操作**：鼠标悬浮到库/文件夹/笔记行上，出现齿轮/⋮/`+` 按钮
- **删除确认**：笔记删除前弹确认框，文件夹/库删除时提示内容会一并移入回收站
- **重名校验**：大小写不敏感；Windows 非法字符过滤；同目录内不允许重名
- **层级限制**：文件夹最多 6 层（不含笔记库）

### 网格视图

点击笔记库标题 → 双击库卡片进入库内容（文件夹+笔记卡片混排）。支持面包屑回跳（面包屑中任意一级可点击回到该级）。双击文件夹进入子层级。Esc 逐级回退。

## 5. 编辑器

### 基本编辑

- **源码编辑**：左侧 CodeMirror 6 编辑器，支持完整的 Markdown 语法
- **实时预览**：右侧实时渲染，代码块语法高亮（16 种语言）、表格、列表、引用等；与编辑器行级双向同步滚动，打开时自动对齐到编辑器当前位置
- **工具栏**：加粗、斜体、删除线、H1/H2、引用、代码、代码块、链接、行内公式、公式块
- **撤销/重做**：工具栏左端或 `Ctrl+Z` / `Ctrl+Shift+Z`

### 所见即所得编辑（Live Preview）

- **进入 / 退出**：编辑器顶栏魔法棒按钮，或 `Ctrl+E` 随时切换；设置 → 通用 → 编辑器可设「默认编辑模式」（打开笔记时用哪种）。顶栏隐藏时（心流，或专注且开启「隐藏顶栏」）切换会在屏幕正中弹出大字提示「所见即所得模式：开 / 关」（浅绿色浮层，2 秒自动消失），无需移动视线去右下角确认
- **长什么样**：非光标区域按渲染后的样子呈现（标题变大、**加粗**生效、公式出图、表格成真表格、frontmatter 折叠为一行）；列表渲染为「•」与编号、任务项渲染为可勾选的复选框、引用只剩左侧引用条（`>` 不显示）；光标所在行回落显示 Markdown 源码，移开即重新渲染
- **什么时候露出源码**：列表 / 引用的标记跟着**光标所在行**走（光标在这一行就整行显示源码）；行内标记（加粗 / 斜体 / 删除线 / 行内码）粒度更细——在文字里编辑（含文字两端、正在输入时）始终保持渲染效果，只有把光标**移到 `~~`、`**`、反引号上（方向键多按一下即可进入）或直接选中它们**，才露出源码；链接、双链、图片、公式则是点击即回落源码
- **呈现边界**：代码块保持源码形态（自带语法高亮）；有序列表保留源编号；光标选中的区域整段回落源码
- **可交互**：任务列表复选框点击即可勾选（自动写回并保存）；双链 `Ctrl+点击` 打开（同名多笔记弹层消歧，断链显示删除线）；外部链接 `Ctrl+点击` 走系统浏览器
- **分栏联动**：进入所见即所得时右侧预览自动收起（内容已所见即所得），切回源码恢复原分栏；悬浮预览、专注模式不受影响
- **放心用**：文件始终是纯 Markdown，所见即所得只是呈现层，保存结果与源码模式完全一致

### 标题层级 / 表格 / 折叠

- **标题**：`Ctrl+1` … `Ctrl+6` 把当前行设为对应级别标题，`Ctrl+0` 清除；已是该级别时再按一次即去掉标记；选中多行时逐行生效。工具栏的「标题」下拉可点选（一级 ~ 六级 + 清除标题）
- **插入表格**：工具栏「表格」按钮或 `Ctrl+T` 弹出尺寸提示浮层——浮层里实时显示将插入的尺寸（默认 2 行 × 2 列）；要其它尺寸就输入「行 列」（例如 `5 6`）再按空格或回车，只输入一个数则列取默认 2；不输入任何数字时按空格或回车即用默认尺寸插入（浮层不会自动消失，一直等你操作），`Esc` 取消。插入后首个表头文字处于选中状态，直接打字即改名；光标在行中时会先换行，表格自成一块
- **表格内跳格**：光标在表格里时 `Tab` / `Shift+Tab` 在单元格之间前后跳转（选中该格内容，可直接覆盖输入）；最后一格按 `Tab` 会自动补一行，第一格按 `Shift+Tab` 离开表格；光标不在表格里时 `Tab` 仍是原来的移动焦点
- **折叠**：把鼠标移到行号右侧的箭头（章节标题、引用、代码块、表格等可折叠处会出现），点击即折叠该段，折叠后在正文里留下「⋯」占位符，再点即展开

### 心流模式（沉浸创作）

- **进入 / 退出**：`Alt + W`，或编辑卡顶栏的咖啡杯按钮；`Esc` 一键退出（无确认）
- **进入时自动**：隐藏侧栏、迷你导航条与顶栏 → 切所见即所得 → 开启打字机（「打字机模式」设为「关闭」时，心流内按低位生效；已选高位 / 低位则沿用）→ 启用写作栏宽与保存指示
- **退出时还原**：侧栏 / 专注 / 预览 / 编辑形态都回到进入前的样子；心流里的临时调整（如 Alt+B 呼出侧栏）不会带出去
- **写作栏宽**：设置 → 通用 → 心流模式，三档（窄 / 中 / 宽）；文本列含行号整体居中，宽屏下长行阅读更省力
- **写作底色**：设置 → 通用 → 心流模式可开启并选色（米黄 / 淡绿 / 淡蓝 / 淡粉 / 淡灰）——给写作栏涂一层柔和的底色帮助视线聚焦；可选「底色过渡」让底色两侧渐变透明（各 15% 栏宽）；底色跟随栏宽，仅心流模式内生效，退出即消失
- **保存指示**：编辑卡右下角一个极小圆点——有未保存变更时淡显、保存中脉冲、保存成功一闪、失败或外部冲突转红；不占布局、不打断输入
- **仍可用**：`Ctrl+F` 全局搜索、`Ctrl+N` 新建笔记、`Alt+B` 浮层侧栏（沉浸模式下侧栏以浮层呼出）
- **快速查阅**：输入 `[[` 后在补全面板选中笔记按 `Alt+Enter`，以悬浮预览看一眼（不切走当前笔记）；预览头部「插入引用」按钮（或再按 `Alt+Enter`）把该笔记落成完整引用并收回预览；**记不住路径时直接输入名字片段**（如 `[[笔记`）即可全库匹配笔记与文件夹（选中文件夹进入逐级导航，`[[/` 从根开始浏览），不用逐级进目录；Esc 先关预览（补全面板保持）、再按收起补全。输入过程中的「断链引用」提示为正常现象：自动保存会把未完成的 `[[` 落盘，引用补全后即消失
- **回车音效**：设置 → 通用 → 心流模式可开启（默认关闭）、选音色并调节音量——复古打字机（默认：按键「咔」+ 推回车棘轮 + 回车铃「叮」，按实录音效重建，整段约 1 秒）/ 推回车（棘轮，约 0.3 秒）/ 回车铃（约 0.8 秒）/ 轮换（三者交替）；回车换行时播放程序合成的音（无音频文件），连续回车自动限流；同组还有「连续换行屏蔽音效」开关（默认开：连按回车加空行时只有第一次发声，避免音效叠在一起）；仅在心流模式内生效，粘贴多行不发声

### 打字机模式

- **开启**：设置 → 通用 → 编辑器 →「打字机模式」，可选 **高位** 或 **低位**
- **高位**：光标所在行始终保持在编辑区垂直居中；**低位**：光标锚定在偏下位置（距底边 20%），刚写下的内容停在光标上方
- **手感**：打字、回车、删除、方向键移动时**文字流动、光标不动**，视线无需跟着光标跑
- **不打扰**：向上滚动查看前文时不会被弹回，下次输入才回到锚点；鼠标拖选过程中不滚动；中文输入法组词期间不跳动
- **两种模式都可用**：源码模式与所见即所得模式均可开启，互不干扰；关闭后滚动行为与常规完全一致

### LaTeX 公式

```
行内公式：$e^{i\pi} + 1 = 0$
块级公式：
$$
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$
```

在列表项中使用：

- 公式独占列表项（多行 `$$` 块或单行 `$$…$$`）→ 以居中展示公式呈现
- 公式写在句子中间（如 `- 结论：$$E=mc^2$$`）→ 自动以行内公式呈现，不破坏句子排版

```
- [x] 已完成的任务
- [ ] 待办任务
1. [x] 有序完成
2. [ ] 有序待办
```

### 双链引用

```
[[目标笔记名]]          # 同库内跳转
[[路径/目标笔记|显示名]]  # 自定义显示名
```

预览中渲染为可点击链接（同库内按名称匹配），断链显示删除线。若同名笔记有多篇（在不同文件夹），点击会弹出候选列表（标题 + 完整路径）供选择跳转。

**反向链接**：编辑卡右下角的悬浮「反向链接」入口（胶囊按钮，含数量角标），点击弹出引用当前笔记的来源笔记列表（仅显示笔记标题），点击条目跳转到来源笔记并定位到引用所在行；按 `Esc`、点击弹层外部或切换笔记即收起。当前笔记没有被引用时不显示。列表随笔记保存 / 外部修改自动刷新，同一笔记的多次引用合并为一条；可在设置 → 通用 → 编辑器 →「显示反向链接」关闭。心流模式下入口默认隐藏（写作零干扰），鼠标移到编辑卡右下角即显现（弹层展开期间保持可见）。

**断链引用**：侧栏在有未解析的 `[[...]]` 引用时显示「断链引用」入口及数量，点击打开断链列表（显示来源笔记、目标名与行号，点击可打开来源笔记）。

**重命名改写**：重命名笔记时，库内其他笔记中的 `[[旧名]]` 会自动改为 `[[新名]]`。

**补全**：输入 `[[` 自动弹出当前库笔记名和文件夹列表，逐级补全——选中文件夹后自动展开下一层子目录/笔记，选中笔记后自动闭合 `]]`。

**预览候选笔记**：补全面板选中一篇笔记后按 `Alt+Enter`，以悬浮预览打开它（不切换当前笔记、不影响已输入的内容），看完点编辑区即收回；悬浮预览里还能点击其中的双链继续看。适合「写到一半想起某篇笔记，先看一眼再决定是否引用」。

### 专注模式

编辑卡顶栏右侧 ⟦ ⟧ 按钮：隐藏侧栏，只留编辑区。专注模式下仍可通过预览按钮呼出预览（编辑/预览各占一半）。再次点击 ⟦ ⟧ 退出。

### 悬浮预览

长按预览按钮（或 `Alt+P`）：悬浮预览卡片从右侧滑入覆盖编辑区，不改变布局。`Esc` / 点空白 / 再次点击关闭。点击编辑区自动收回。呼出时自动同步到编辑器当前所在位置（不是从文档开头显示）。

### 图片

粘贴或拖入图片：自动保存到库的附件目录（默认 `attachments/`，可在设置中改为多级目录如 `media/image`），笔记中以相对路径引用。

## 6. Markdown 语法支持

标准 Markdown + 扩展语法：

| 语法 | 示例 |
| --- | --- |
| 加粗 | `**文本**` |
| 斜体 | `*文本*` |
| 删除线 | `~~文本~~` |
| 标题 | `# 一级` / `## 二级` |
| 引用 | `> 引用内容` |
| 代码块 | ` ```js ... ``` ` |
| 表格 | `\| 列1 \| 列2 \|` |
| 图片 | `![alt](./attachments/img.png)` |
| 内嵌 HTML | `<details><summary>折叠</summary>内容</details>`（经 DOMPurify 净化） |
| LaTeX 行内 | `$e^{i\pi}+1=0$` |
| LaTeX 块级 | `$$ ... $$` |
| 双链 | `[[目标笔记]]` / `[[路径/显示名\|别名]]` |
| 锚点链接 | `[跳转](#标题id)` |
| 任务列表 | `- [x]` / `- [ ]`（只读复选框） |

## 7. 图片与附件

- **粘贴/拖入**：图片自动保存到附件目录（默认 `attachments/`，可在设置中自定义，支持多级路径如 `media/image`）
- **相对引用**：笔记中以相对路径引用图片
- **预览渲染**：预览中图片通过自定义协议（`trace-vault://`）加载
- **导出时内联**：PDF/HTML 导出时图片自动转为 base64 data URI，文件自包含

## 8. Git 同步

### 登录与配置

## 13. 冲突解决

当 Git 同步发生冲突时，Trace 会弹出图形化冲突解决界面，帮助您轻松解决冲突：

### 冲突检测

同步过程中如果本地修改与远程修改发生冲突，应用会自动检测并弹出冲突解决对话框。

### 解决界面

- **左侧**：冲突文件列表，显示所有存在冲突的文件
- **右侧**：三方对比视图，可查看本地版本、远端版本、共同祖先版本
- **操作按钮**：接受本地版本、接受远端版本、手动编辑

### 解决流程

1. 在左侧选择冲突文件
2. 查看三方对比内容，理解冲突原因
3. 选择解决方式：接受本地版本、接受远端版本，或手动编辑内容
4. 重复以上步骤解决所有冲突文件
5. 点击「继续同步」完成同步，或点击「放弃所有更改」中止同步

> 详细操作说明请参阅「8. Git 同步 > 关联与同步 > 冲突解决」部分。

## 14. 全局搜索

Trace 支持跨笔记库的全局搜索功能，帮助您快速找到需要的笔记内容。

### 搜索入口

- **侧栏搜索按钮**：点击侧栏标题行右端的搜索图标 🔍
- **快捷键**：`Ctrl+F`（Windows/Linux）或 `Cmd+F`（macOS），编辑器内同样生效（不会触发编辑器原生搜索）

### 搜索功能

- **全文搜索**：可搜索笔记标题和正文内容
- **实时搜索**：输入关键词后自动搜索（300ms 防抖），也可按回车或点「搜索」按钮
- **结果排序**：按相关度排序，标题匹配优先
- **匹配高亮**：搜索结果中高亮显示匹配的关键词
- **快速跳转**：点击搜索结果直接打开对应笔记；也可用键盘——`↓` / `↑` 在结果间移动高亮（循环、自动滚动跟随），`Enter` 打开高亮项，`Alt+Enter` 关闭搜索框并以悬浮预览看一眼（`Ctrl+F` 可重开搜索）
- **结果信息**：每条结果显示笔记标题、匹配行号、内容片段、所属库名与路径

### 搜索选项

- **搜索字段**：「标题」「内容」复选框，可任选组合；勾选/取消后立即生效，自动重新搜索（两者都取消时自动恢复「内容」）
- **搜索范围**：搜索框右侧的下拉按钮，显示「所有库」或已选库名/数量
  - 下拉列表含「所有库」+ 全部库名，可多选
  - 点击「所有库」切换全选/全不选；全不选时所有库名的勾选框自动取消
  - 自定义模式下勾选库名可多选；全部勾选时自动回到「所有库」
  - 未选择任何库时，按钮变红并提示「请选择至少一个笔记库」

### 索引管理

- 应用启动时会自动构建搜索索引
- 可手动重建索引：点击搜索对话框底部的「重建索引」按钮
- 索引状态：对话框底部显示已索引的笔记数量

## 15. 插件

### 插件是什么

插件是放在应用数据目录 `plugins/<插件id>/` 中的扩展程序，可以读写你的笔记、响应保存/同步等事件、向界面发送通知。每个插件运行在独立进程中：插件崩溃不影响笔记与应用本身，系统会自动重启它（连续崩溃 5 次会自动停用并标记错误）。

### 启用插件

1. 打开 设置（`Ctrl+,`）→ 插件
2. 打开「启用插件」总开关
3. 在「已安装的插件」列表中打开对应插件的开关
4. **权限确认**：首次启用（或插件更新后权限变化）会弹窗列出插件请求的全部权限（如「读取笔记内容与列表」「创建和修改笔记」），确认无误后点「确认并启用」

> 请仅启用你信任的插件。本地安装的插件未经 Trace 市场审阅。

### 运行插件命令

插件运行后，其注册的命令会以按钮形式显示在设置页对应插件行下方，点击即可执行（例如示例插件的「统计首篇笔记」会读取第一个库的第一篇笔记统计字数，并把结果写入「插件示例报告.md」）。

### 插件市场

设置 → 插件 → 「插件市场」区块可直接浏览并安装社区插件：

- **安装**：点「安装」→ 弹窗确认权限（市场插件已通过审阅，安装时还会校验安装包与索引登记的校验和一致）
- **更新**：插件行出现「更新到 x.y.z」按钮时点击即可（更新重走权限确认；新版本新增权限时需再次确认）
- **刷新**：市场列表每 24 小时自动更新，也可点「刷新」手动拉取；网络失败时显示本地缓存
- **下架**：被市场下架的插件会标记「已下架」，已安装的仍可继续使用，只是不再提供更新
- 网络请求跟随 设置 → 通用 中的 HTTP/HTTPS 代理

想上架自己的插件？见 [plugin-release.md](plugin-release.md) 发布指南。

### 导入 / 导出插件

- **导入**：设置 → 插件 → 「导入插件…」，选择 `.trace-plugin` 插件包文件；弹窗会显示插件信息与请求的权限，确认后完成安装（本地导入的插件未经 Trace 市场审阅，请确认来源可信）
- **升级**：导入同 id 的新版本插件包即为升级覆盖；若新版本请求了新权限，启用前会要求重新确认
- **导出**：插件「详情」中「导出…」可把已安装的插件打包为 `.trace-plugin` 文件分享给他人

### 查看插件详情与卸载

- 插件行「详情」按钮：查看运行状态、权限清单、崩溃历史（时间与退出码）、最近日志与私有存储占用
- 「卸载」：删除插件目录、权限记录与私有存储，不可恢复（红色确认）

### 插件界面扩展

- **编辑器工具栏**：声明了 `editor:toolbar` 权限的插件可在编辑器工具栏贡献按钮（如示例插件的「∑ 统计字数」），点击执行插件命令；插件停止后按钮自动消失
- **侧栏状态区**：声明了 `ui:status` 权限的插件可在侧栏底部显示一行文字（如最近保存状态），插件停止后自动清除

### 插件私有存储

插件可以把配置等状态保存到宿主托管的私有存储（按插件隔离），卸载插件时一并清除；占用大小在插件详情中可见。

### 示例插件

首次启动时应用会自动放置一个「示例插件」，演示全部基础能力：读取笔记、创建/写入笔记、订阅保存事件、注册命令。可作为开发插件时的参考（manifest.json 声明元信息与权限，main.js 导出 `activate(ctx)`）。

> 想自己写插件？见 [plugin-development.md](plugin-development.md) 开发指引（API 参考、权限说明、完整示例与调试方法）。

### 常见问题

- **插件显示「需确认权限」**：插件更新后请求了新权限，重新打开开关确认即可
- **插件显示崩溃次数**：插件运行中反复出错，系统会自动重启；连续 5 次失败后自动停用，可联系插件作者修复
- **插件没有反应**：确认「启用插件」总开关与插件开关都已打开、权限已确认、状态显示「运行中」
