# 主题包导入使用指引

Trace 支持从本地 JSON 文件导入**自定义主题**（一组 CSS 颜色变量，含浅色 / 深色两套），导入后在设置页与内置预设（Trace / 暖色 / 冷色 / 高对比度）并列显示、一键切换，可随时删除。本文说明如何编写与使用主题包。

## 一、导入 / 使用 / 删除

入口：**设置 → 通用 → 外观 → 配色**。

- **导入**：点击配色网格末尾的虚线「＋ 导入主题」卡片 → 选择 `.json` 文件。校验通过后主题卡片出现并自动选中、界面即时生效。
- **切换**：点击任意主题卡片（内置或自定义）即可应用；浅色 / 深色 / 跟随系统由上方「主题」单选独立控制，与主题包互不影响。
- **覆盖**：导入的 `id` 与已有自定义主题相同时，会弹「已存在主题，覆盖更新？」确认；确认后替换。
- **删除**：鼠标悬停在自定义主题卡片上，点右上角删除图标 → 确认。删除当前正在使用的主题会自动回退到默认 Trace 配色。

> 主题包按文件独立存放于应用数据目录（`themes/<id>.json`），**不会写入任何笔记库**，也不影响 git 仓库。

## 二、文件格式

主题包是一个 UTF-8 编码的 `.json` 文件，结构如下：

```json
{
  "id": "sakura",
  "name": "樱花",
  "light": {
    "--bg-primary": "#fff7f9",
    "--accent": "#e07a9b"
  },
  "dark": {
    "--bg-primary": "#1e1519",
    "--accent": "#f2a3bd"
  }
}
```

### 字段规则

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `id` | 是 | 主题唯一标识。只能用小写字母、数字、连字符（`-`），且以字母或数字开头，最长 64 字符。内置保留 id（`default`、`warm`、`cool`、`high-contrast`）不可使用。 |
| `name` | 是 | 设置页显示的名称，1–30 字。 |
| `light` | 是 | 浅色模式的变量覆盖，对象（可为空 `{}`）。 |
| `dark` | 是 | 深色模式的变量覆盖，对象（可为空 `{}`）。 |

- `light` 与 `dark` **必须同时存在**，但内部变量都可以只写一部分：未写的变量自动继承默认 Trace 配色（因此可以只改主色调）。
- 变量键必须来自下方白名单；**出现未知变量或未知字段会拒绝导入**并提示，便于排查拼写错误。
- 变量值为颜色字符串，最长 64 字符，不允许分号、冒号、大括号、尖括号、引号、反斜杠等结构字符（防止样式逃逸与外部请求）。

## 三、可用变量（19 项）

| 分类 | 变量 | 用途 |
| --- | --- | --- |
| 背景 | `--bg-primary` | 卡片、面板主背景 |
| 背景 | `--bg-secondary` | 画布 / 次级背景 |
| 背景 | `--bg-tertiary` | 更深一层的背景 |
| 背景 | `--bg-hover` | 悬停底色 |
| 背景 | `--bg-active` | 选中 / 激活底色 |
| 文字 | `--text-primary` | 主文字 |
| 文字 | `--text-secondary` | 次级文字 |
| 文字 | `--text-tertiary` | 弱化文字、占位符 |
| 边框 | `--border-color` | 边框、分隔线 |
| 强调 | `--accent` | 主题强调色（按钮、选中态） |
| 强调 | `--accent-soft` | 强调色的浅底（通常带透明度） |
| 强调 | `--danger` | 危险 / 删除操作色 |
| 代码 | `--code-bg` | 代码块背景 |
| 代码高亮 | `--hljs-base` | 代码默认文字 |
| 代码高亮 | `--hljs-comment` | 注释 |
| 代码高亮 | `--hljs-keyword` | 关键字 |
| 代码高亮 | `--hljs-string` | 字符串 |
| 代码高亮 | `--hljs-number` | 数字 |
| 代码高亮 | `--hljs-title` | 函数 / 标题名 |

颜色可写十六进制（`#e07a9b`）、`rgb()/rgba()`、`hsl()/hsla()` 或 CSS 颜色名；带透明度的变量（如 `--bg-hover`、`--accent-soft`）建议用 `rgba(...)`。

## 五、常见错误与解决

| 提示 | 原因 / 解决 |
| --- | --- |
| 无法读取或解析该文件（需为合法 JSON） | 文件不是合法 JSON：检查括号 / 逗号 / 引号，确保为 UTF-8 编码。 |
| id 需为小写字母、数字或连字符…… | `id` 用了大写、空格、斜杠等；改为如 `my-theme`。 |
| id「warm」为内置保留主题 | `id` 与内置主题重名，换一个。 |
| name 需为 1–30 个字符 | 补上名称或缩短。 |
| 缺少 light 或 dark | 两个键都要有（没有覆盖内容可写空对象 `{}`）。 |
| 未知变量 `--xxx` | 变量名拼错或不在白名单，对照第三节。 |
| 变量 `--xxx` 的值非法 | 值为空、过长，或含 `;` `:` `{` `}` 等结构字符。 |
| 未知字段 `xxx` | 顶层多了不认识的键，只允许 `id` / `name` / `light` / `dark`。 |

## 六、注意事项

- 只想小改：可以只写少数变量，其余自动继承默认配色；但只覆盖一部分时，个别地方可能与整体不协调，建议至少同时调整背景与文字色。
- 深浅两套独立：`light` 用于浅色 / 跟随系统的浅色，`dark` 用于深色；只调一套时另一套仍为默认。
- 主题包仅影响界面配色，不改动笔记内容或插件行为。
- 删除主题文件后，若它正被使用，界面会自动回退到默认 Trace 配色（重启后同样回退）。
