## 一、已实现并发布（v0.1.0 → v0.3.3）

### v0.1.0 / v0.2.0 基线（PRD 全部需求）

- **工作区 / 笔记库 / 文件夹 / 笔记管理**：默认工作区创建与更换、六级文件夹、全程重名校验与非法字符过滤、chokidar 外部变更感知（FR-2.1~2.3）
- **编辑器与预览**：CodeMirror 源码 + 实时预览、LaTeX / 代码高亮、工具栏、1s 防抖自动保存、外部修改 hash 保护、三栏圆角卡片布局、预览收缩、专注模式、悬浮预览（长按）、分栏拖拽（FR-2.4 / 2.9）
- **图片附件**：粘贴 / 拖入自动存附件目录、相对路径引用、`trace-vault://` 协议加载、附件目录可配置（FR-2.5）
- **收藏 / 常用 / 回收站**：收藏跟随重命名、常用上限 20、应用级回收站还原 / 彻底删除 / 清空（FR-2.6 / 2.7）
- **Git 云同步**：GitHub PAT 登录（safeStorage + 引导）、关联 / 新建远程仓库、一键同步（提交→拉取→推送）、冲突检测保护本地、状态徽标（FR-2.8）
- **主题 / 设置 / 插件 v1 骨架**：三态主题、三标签设置页、manifest + 加载器 + 示例插件（FR-2.9~2.11）

### v0.3.1（2026-09-07）

- 常用 / 收藏卡片网格视图（单击悬浮预览、双击编辑、卡片 ⋮ 菜单：收藏 / 移出常用 / 删除）
- 取消收藏（收藏区菜单 + 树菜单状态感知）
- 修复：移出常用不刷新、菜单残影闪现（popper 锚点竞态）、专注模式不隐藏预览
- 侧栏「常用 / 收藏」改单行入口（语雀式）、回收站卡片化列表、菜单顺序统一（删除置底红字）、展开箭头美化

- 发版一致性：CI 校验 tag 与 package.json 版本、`npm version` 一键发版（postversion 自动推标签）
