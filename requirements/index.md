## 一、已实现（v0.1.0 → v0.5.1，发布状态见子节）

### v0.5.1（2026-09-21）

- **插件设置页区块重排**：「已安装的插件」上移至「插件市场」之前，市场插件增多时已安装列表不再被挤出首屏
- **Linux 移除窗口底部圆角**：浅色壁纸下圆角缺口残留系统合成器方形轮廓（已知问题毕业，规避处理）——Linux 平台一律禁用内容区底部圆角，Windows / macOS 保留
- **构建**：插件类型包 `trace-plugin-api` 改为 CI 自动发布（npm Trusted Publishing / OIDC；首次使用前需在 npmjs.com 登记 Trusted Publisher，见 [guides/plugin-development.md](../../guides/plugin-development.md) 第 9 节）

### v0.5.0（2026-09-21）

- **插件系统完整落地（M1–M4，FR-2.11.5–2.11.14）**：
  - **进程隔离与稳定性**：每插件独立 utilityProcess；崩溃守护指数退避重启、连续 5 次自动停用；能力网关按 manifest 权限过滤，require 白名单（自包含政策）
  - **能力 API**：notes 读写（含防覆盖 hash）/ 事件订阅 / 通知 / 日志 / 命令注册 / 私有 KV 存储 / 状态区；全部调用走 RPC（5s 超时、内容大小上限、事件合并节流）
  - **权限确认**：首次启用与权限变化时弹窗逐项确认（中文说明），确认记录随插件管理
  - **.trace-plugin 打包导入导出**：zip 自包含格式，导入带 zip-slip / 炸弹防护与权限确认弹窗（本地包显著提示未经审阅）；同 id 升级覆盖
  - **设置页详情与卸载**：状态 / 权限 / 崩溃历史 / 日志 / 存储占用；卸载清除目录、权限记录与私有存储
  - **声明式 UI 扩展**：编辑器工具栏按钮（contributions.toolbar）与侧栏状态区（ctx.status），插件不碰 DOM
  - **应用内插件市场**：索引仓库 `imnot70/trace-plugins`（PR 审阅治理），浏览 / 安装（下载 → sha256 版本锁定 → 复用导入管线）/ 更新检查 / 下架标记；网络跟随代理设置
  - **`trace-plugin-api` 类型包**（packages/plugin-api，npm 发布待办）；示例插件 v2.2.0 覆盖全部能力演示
  - 详见 [plugin-design.md](2026-09-08_plugin-system/plugin-design.md) 第 10–13 节实施记录；开发指引 [guides/plugin-development.md](../../guides/plugin-development.md)、发布指引 [guides/plugin-release.md](../../guides/plugin-release.md)

### v0.4.4（2026-09-18）

- **全局搜索**（FR-2.9 扩展）：侧栏新增搜索按钮（Ctrl+F），支持跨笔记库全文搜索；可按标题/内容筛选，搜索范围下拉多选（所有库或指定库）；搜索结果按相关度排序，显示标题、行号、片段、库名与路径，关键词高亮；点击结果直接打开笔记；索引自动构建，支持手动重建。
- **双链引用 P3**（FR-2.4.11 扩展）：笔记重命名自动改写库内 `[[旧名]]`；编辑卡右下角「反向链接」悬浮入口 + 弹层（仅显示来源笔记标题，多次引用合并，随保存 / 外部修改自动刷新）；侧栏「断链引用」入口与断链列表视图。索引由文件监听增量更新（保存 / 外部编辑 / git 同步后均新鲜）；修复索引运行期不更新、同行多引用互相覆盖、路径形式双链误报断链、跨库同名误配等问题。详见 [wiki-link-anchor_design.md](2026-09-12_wiki-link-anchor/wiki-link-anchor_design.md) 第 7 节。
- **侧栏菜单开关**（FR-2.9.2 扩展）：设置 → 通用 → 侧栏菜单可分别显示 / 隐藏「常用 / 收藏 / 标签 / 断链引用 / 回收站」（「笔记库」始终显示）；快捷入口区与笔记库区之间新增分隔线。设置 → 通用 → 编辑器新增「显示反向链接」开关，控制编辑卡右下角反向链接入口。
- **图形化冲突解决**（FR-2.8.6 扩展）：同步冲突时保留冲突状态（不自动中止 rebase），弹出图形化解决界面；支持查看三方对比（本地/远端/共同祖先）、逐文件解决（接受本地版本、接受远端版本、手动编辑）、解决后继续同步或放弃所有更改（中止 rebase）。
- **自动同步变更触发模式**（FR-2.8.14 扩展）：保存笔记后 5 秒自动同步已关联远程仓库的笔记库，连续变更合并为一轮，单轮未完成时轮次结束后补跑；设置改为方式选择（关闭 / 定时 / 变更触发），兼容旧 autoSyncEnabled。
- **窗口半透明+毛玻璃效果**（FR-2.9 扩展）：设置 → 通用 → 外观新增窗口效果和透明度控制；支持 Windows 11 Mica/Acrylic、macOS 毛玻璃，Linux 依赖桌面合成器；透明度可调，自动模式按平台选择最佳效果。
- **窗口底部圆角**：内容区底部两角圆角化（10px），透明窗口关闭系统方形投影，圆角在深色壁纸下干净（浅色壁纸残留问题见第二节已知问题）。
- **窗口最小宽度保护**（已知局限毕业）：编辑区 min-width 480px、预览区 280px，非编辑视图页卡片 min-width 500px。
- **导出合并 PDF**（FR-2.4.10 扩展）：文件夹/整库菜单「导出合并 PDF…」，多篇合并为单个 PDF（pdf-lib 拼接），顺序与源文件一致，图片/公式/代码块全保真。
- **双链补全优化**：`[[` 补全改为逐级路径补全，选中文件夹自动展开下一层。
- **修复**：回收站列表同毫秒批量删除时排序不稳定（容量上限 flaky 测试）。
