## 0. 产品定位

Trace（中文名「笔迹」）是一款**本地优先**的轻量级 Markdown 笔记应用：

- 笔记以纯 Markdown 文件存储，**无私有格式**，任何编辑器都能打开；
- 每个笔记库是一个独立 git 仓库，天然支持**多设备同步与版本历史**；
- 支持 LaTeX 公式、图片粘贴、主题与插件，以及面向创作的**心流模式**（沉浸预设 + 打字机 + 回车音效）；
- 跨平台：Windows / macOS / Linux（Ubuntu、Debian 系为主）。

三条产品原则：

1. **文件是唯一事实来源**——应用的所有数据（笔记、图片）都是磁盘上可见的普通文件，应用元数据（设置、收藏等）与笔记数据严格分离，不污染笔记库；
2. **不悄悄丢数据**——保存有外部修改检测，删除先进回收站，危险操作红色警示；
3. **对普通用户友好**——无需理解 git 也能完成云端同步，关键流程有分步引导。

## 1. 术语表

| 术语 | 含义 |
| --- | --- |
| 工作区 | 所有笔记库的父目录，默认 `~/Trace`，可更换 |
| 笔记库 | 工作区下的一个一级文件夹 = 一个独立 git 仓库，按主题组织 |
| 文件夹 | 笔记库内的子目录，可多级嵌套（最多 6 层） |
| 笔记 | 一份 `.md` 文件，文件名即笔记名 |
| 附件目录 | 库内存放粘贴图片的目录，可配置（默认 `attachments`） |
| 回收站 | 工作区下的 `.trash/`，应用级删除缓冲区 |
| 专注模式（Zen） | 隐藏侧栏、只保留编辑卡片的沉浸式编辑状态 |
| 悬浮预览 | 覆盖在编辑区上方的浮动渲染预览卡片 |

## 2. 功能需求

### 2.1 工作区

- FR-2.1.1 首次启动自动创建默认工作区 `~/Trace` 并启用。
- FR-2.1.2 可在设置中更换工作区目录（目录选择器 + 应用按钮），生效后刷新全部数据并关闭已打开的笔记；工作区目录必须可写。
- FR-2.1.3 更换工作区后，笔记库列表、回收站随新目录切换。

### 2.2 笔记库

- FR-2.2.1 创建：输入名称，系统校验（见 4.2）；创建后出现在侧栏「笔记库」区。
- FR-2.2.2 重命名：库齿轮菜单中操作，校验规则同创建。
- FR-2.2.3 删除：确认弹窗提示「库中全部内容将一并移入回收站」；删除后库整体（含 `.git`）进入回收站。
- FR-2.2.4 库行操作按钮：齿轮（关联 Git / 立即同步 / 解除关联 / 重命名 / 删除笔记库）与 `+`（新建文件夹 / 创建笔记）。

### 2.3 文件夹与笔记

- FR-2.3.1 层级：文件夹最多 6 层（不含笔记库），超限提示「已达最大层数」。
- FR-2.3.2 创建 / 重命名 / 删除：文件夹与笔记均支持；重名校验与非法字符校验贯穿所有操作（规则见 4.2）。
- FR-2.3.3 笔记名即文件名（自动补 `.md`），界面显示去 `.md`。
- FR-2.3.4 行操作按钮（悬浮显示）：文件夹有 `+`（新建文件夹 / 创建笔记）与 `⋮`（重命名 / 删除）；笔记有 `⋮`（重命名 / 删除 / 收藏）。
- FR-2.3.5 删除类菜单项以红色字体警示；删除操作有确认弹窗。
- FR-2.3.6 侧栏树实时反映磁盘变化（chokidar 监听，git 拉取 / 外部编辑器改动均能感知；git 同步期间挂起监听避免自我触发）。
- FR-2.3.7 定位笔记：在侧栏树中展开并高亮目标节点（库 / 文件夹 / 笔记），滚动到可视区，高亮约 2 秒后淡出。入口：编辑卡顶栏「定位」按钮（十字准星图标，定位当前笔记）；网格卡片 ⋮ 菜单「在侧栏中定位」（库 / 文件夹 / 笔记卡片均有）。侧栏收起时自动恢复侧栏；专注模式下以浮层侧栏展示定位结果，不打断沉浸。
- FR-2.3.8 位置上下文：应用维护「最近导航到的库与文件夹」（打开笔记 / 网格钻入库或文件夹 / 侧栏点击库与文件夹行均更新；库重命名 / 删除时迁移与清理），作为 `Ctrl+N` 新建笔记的目标；无上下文时兜底第一个笔记库。

### 2.4 笔记编辑器

- FR-2.4.1 形态：左侧源码编辑（CodeMirror 6）+ 右侧实时渲染预览，中间分隔条可拖拽调整比例（20%–80%），双向滚动按源码行号映射联动（见 [preview-enhancement-design.md](2026-09-09_preview-enhancement/preview-enhancement-design.md)）。
- FR-2.4.7 内嵌 HTML：笔记中的内嵌 HTML 在预览中渲染（markdown-it `html: true`）；渲染输出经 DOMPurify 白名单净化（剥除脚本 / 样式注入 / base / 表单 / 事件属性，防同步投毒笔记的视觉钓鱼与导航劫持），CSP 追加 `form-action 'none'`。
- FR-2.4.8 链接跳转：预览中链接（markdown 与原始 HTML 两种来源）统一事件委托处理——外部 http(s) 链接经系统浏览器打开；指向库内笔记的相对路径链接（`./笔记.md` 等）在应用内直接打开；断链渲染为删除线样式并轻提示。双链同名多篇（不同文件夹）时点击弹出候选列表（标题 + 完整路径）消歧，唯一匹配直接打开。该"相对引用解析 → 校验 → 打开"管道与二期 wiki 双链共享。
- FR-2.4.9 HTML 标签自动闭合：编辑器中输入 HTML 开标签的 `>` 时自动生成闭合标签，自闭合标签（`<br>`, `<img>` 等）不触发。
- FR-2.4.10 导出 PDF：侧栏树与网格卡片 ⋮ 菜单「导出 PDF…」，支持单篇、文件夹递归与整库批量（可跨库多次执行）；每篇一个独立 PDF（Chromium printToPDF 管线，白底黑字打印样式，代码块 / 表格 / 引用防跨页截断）；库内图片内联 base64 使 PDF 自包含；批量导出带进度展示与失败汇总（单篇失败不中断）；导出目录会话内记忆，文件名规则 `库名-路径.pdf`（重名追加序号）；支持将多篇合并为单个 PDF（pdf-lib 拼接）。设计见 [note-export/note-export-design.md](note-export/note-export-design.md)。
- FR-2.4.11 双链补全：编辑器输入 `[[` 时自动补全当前库内的笔记路径（排除当前笔记自身，支持路径过滤）；与 FR-2.4.8 的跳转管道配套。补全面板选中笔记按 **Alt+Enter** 可将该笔记以悬浮预览打开（不切换当前笔记、不插入文本、补全保持打开；悬浮预览内点击双链为预览内导航）——心流下「先看一眼再决定是否引用」的快速查阅动线。
- FR-2.4.11.1 反向链接：编辑卡右下角悬浮「反向链接」入口（胶囊按钮 + 数量角标，随笔记保存 / 外部修改自动刷新，受设置 → 通用 → 编辑器 →「显示反向链接」开关控制），点击弹出引用当前笔记的来源笔记列表（仅显示笔记标题，同一笔记多次引用合并为一条），点击条目跳转到来源笔记并定位到引用所在行；当前笔记没有被引用时不显示。侧栏「断链引用」入口，有未解析的 `[[...]]` 引用时显示数量，点击打开断链列表视图。
- FR-2.4.11.2 双链改写：笔记重命名时自动将库内其他笔记中的 `[[旧名]]` 改写为 `[[新名]]`。
- FR-2.4.12 导出 HTML：侧栏树与网格卡片 ⋮ 菜单「导出 HTML…」，范围与 FR-2.4.10 一致（单篇 / 文件夹递归 / 整库批量）；每篇一个自包含 HTML（居中限宽阅读排版，随系统深浅色，公式 CSS 与字体 data URI 内联，图片 base64），同名自动追加序号。渲染管道与 FR-2.4.10 共用（frontmatter 不进导出内容）。设计见 [2026-09-15_note-export-html/note-export-html_design.md](2026-09-15_note-export-html/note-export-html_design.md)。
- FR-2.4.13 所见即所得编辑模式（Live Preview，Obsidian 式）：编辑器可在源码模式与所见即所得间切换（顶栏按钮 / `Ctrl+E`），设置可配默认模式。所见即所得下非光标区域按渲染形态呈现（标题 / 粗斜体 / 删除线 / 行内码 / 引用 / 任务列表（可点击勾选）/ 表格 / LaTeX 公式 / 图片 / 双链 / 内嵌 HTML / frontmatter 折叠），光标所在区域回落显示源码；进入时自动收起预览分栏、退出恢复。**源码露出的粒度分两级**：行级结构（列表 / 引用标记）按「光标所在行」回落；行内标记（加粗 / 斜体 / 删除线 / 行内码）只在光标**贴到或选中定界符**时回落，在内容里（含内容两端与输入过程中）始终保持渲染；链接 / 双链 / 图片 / 公式等 widget 仍为「光标进入即回落」，便于点击后直接编辑。列表 / 引用的标记随渲染隐藏（无序列表呈「•」、有序列表保留编号、任务项由复选框取代、引用 `>` 隐藏）；块级 widget（公式块 / 表格 / HTML 块 / 水平线）的占位高度与行号列严格对齐。文件始终为纯 Markdown，保存产物与源码模式一致。设计见 [2026-09-21_wysiwyg/wysiwyg_design.md](2026-09-21_wysiwyg/wysiwyg_design.md)；2026-09-24 的呈现修正与粒度调整见 [2026-09-24_live-preview-render-fix/](2026-09-24_live-preview-render-fix/live-preview-render-fix.md)。
- FR-2.4.14 打字机模式：设置 → 通用 → 编辑器分组可选「高位」（光标垂直居中）/「低位」（光标锚定在距底边约 20% 处），输入时文字流动、光标位置不动；用户滚动查看前文时不干预、下次输入回到锚点，拖选中与输入法组词期间不重锚；源码与所见即所得两种编辑形态均可用。属「心流模式」三期计划的第一期（三期均已实施，见 FR-2.9.8 / FR-2.9.9），设计见 [2026-09-23_flow-mode/](2026-09-23_flow-mode/flow-mode_design.md)。
- FR-2.4.15 标题层级快捷键：编辑器内 `Ctrl+1` … `Ctrl+6` 将当前行设为对应级别标题、`Ctrl+0` 清除标题；已是目标级别时再按一次即去掉标记（开关语义）；多行选择逐行生效，单次操作可一步撤销。工具栏提供「标题」下拉（一级 ~ 六级 + 清除标题，菜单项显示快捷键）。设计见 [2026-09-24_editor-tools/](2026-09-24_editor-tools/editor-tools.md)。
- FR-2.4.16 表格插入：工具栏「表格」按钮或 `Ctrl+T` 进入**尺寸输入提示态**（FR-2.4.20），按尺寸在光标处插入 GFM 表格模板，插入后选中首列表头占位文字便于直接改名；光标行此前已有内容时先换行，保证表格独占行块。设计见 [2026-09-24_editor-tools/](2026-09-24_editor-tools/editor-tools.md) 与 [2026-09-24_table-insert-enhance/](2026-09-24_table-insert-enhance/table-insert-enhance.md)。
- FR-2.4.17 折叠按钮（层级 / 块内容）：行号列右侧的折叠箭头使用与应用一致的线性图标（16px，热区 ≥20×20，悬停圆角背景）；折叠范围与出现场景沿用编辑器默认（标题层级、块引用、代码块、HTML 块、表格），折叠后的「⋯」占位符样式不变。设计见 [2026-09-24_editor-tools/](2026-09-24_editor-tools/editor-tools.md)。
- FR-2.4.18 编辑位置：设置 → 通用 → 编辑器 →「编辑位置」可选「从头开始」（默认）/「从尾部开始」，决定打开笔记后光标落在文首还是文末（视图随光标滚动到位；心流模式内打开的笔记同样生效）；与「上次编辑位置」无关，重命名与外部修改重载不移动光标。设计见 [2026-09-24_edit-position/](2026-09-24_edit-position/edit-position.md)。
- FR-2.4.19 光标跳转文件头 / 尾：编辑器内 `Ctrl+Shift+H` 跳到文件开头、`Ctrl+Shift+E` 跳到文件末尾（主键盘区键位，笔记本上无需 Fn）；源码与所见即所得模式均可用，与既有 `Ctrl+Home` / `Ctrl+End` 并存。设计见 [2026-09-24_edit-position/](2026-09-24_edit-position/edit-position.md)。
- FR-2.4.20 表格尺寸输入（带实时反馈）：`Ctrl+T` / 工具栏按钮进入提示态并在光标附近弹出浮层——实时回显将插入的行列数（默认 2 行 × 2 列）、操作提示与默认行为预告；输入「行 列」（如 `5 6`）后空格或回车插入（只给行数时列取默认 2），未输入数字时直接空格 / 回车即按默认尺寸插入——**不设倒计时自动插入**，浮层一直等待用户操作，`Esc` / 点击他处 / 失焦取消（不写入正文）；取值范围行 1–50、列 1–20，超限时浮层红字提示并按上限处理。设计见 [2026-09-24_table-insert-enhance/](2026-09-24_table-insert-enhance/table-insert-enhance.md)。
- FR-2.4.21 表格内 Tab 跳转：光标位于表格内时 `Tab` / `Shift+Tab` 在单元格之间前后跳转（行优先，从表头行开始），跳转后选中该单元格内容便于直接覆盖输入；最后一格 `Tab` 追加一行并落在新行首格；第一格 `Shift+Tab` 离开表格；表格外 `Tab` 行为不变（移动焦点），补全浮层打开时让位；源码与所见即所得模式均可用。设计见 [2026-09-24_table-insert-enhance/](2026-09-24_table-insert-enhance/table-insert-enhance.md)。
- FR-2.4.2 语法支持：完整 Markdown + LaTeX 公式（行内 `$...$`、块级 `$$...$$`，KaTeX 渲染）+ 代码块语法高亮（常用 16 种语言）+ GFM 任务列表（`- [x]` / `- [ ]`，只读复选框）。
- FR-2.4.3 工具栏（编辑卡片内）：撤销、重做、加粗、斜体、删除线、标题（一级 ~ 六级 + 清除，FR-2.4.15）、引用、行内代码、代码块、链接、表格（FR-2.4.16）、行内公式、公式块。
- FR-2.4.4 保存：编辑后 1 秒防抖自动写盘（可关闭）；`Ctrl+S` / `Cmd+S` 手动保存。
- FR-2.4.5 外部修改保护：以磁盘内容 hash 比对。
  - 无未保存改动 → 静默重载；
  - 有未保存改动 → 顶部横幅提供「放弃本地修改并重载 / 保留本地修改继续编辑」；
  - 本地保存时若磁盘 hash 不一致 → 拒绝写入，防止覆盖；
  - **回声抑制**：应用自身的保存写入同样会触发文件监听，检测前先读磁盘与最后写入内容比对，一致即忽略——横幅只在真正的外部修改时出现。
- FR-2.4.6 笔记标题面包屑显示在编辑卡片顶部，含未保存圆点标识。

### 2.5 图片与附件

- FR-2.5.1 粘贴 / 拖入图片：自动保存到库内附件目录，文件名加时间戳前缀防重名，笔记中插入相对路径引用。
- FR-2.5.2 附件目录可配置（设置 → 通用）：相对库根的多级路径（如 `media/image`，最多 4 层）；修改仅对之后粘贴的图片生效。
- FR-2.5.3 预览中相对路径图片通过自定义协议 `trace-vault://<库名>/<路径>` 加载显示。

### 2.6 收藏与常用

- FR-2.6.1 收藏：笔记 `⋮` 菜单收藏 / 取消；侧栏「收藏」区直达。
- FR-2.6.2 收藏跟随：笔记重命名 / 父文件夹或库重命名 / 删除时自动更新或清理引用。
- FR-2.6.3 常用：最近打开的笔记，时间倒序，上限 20 条；卡片底部显示相对时间（「3 分钟前」「2 天前」等）。
- FR-2.6.4 高亮规则：侧栏（常用 / 收藏 / 树）中当前打开笔记的行带底色，且仅当正处于编辑视图时显示。
- FR-2.6.5 卡片网格交互（常用 / 收藏 / 笔记库网格）：笔记卡片**单击**呼出悬浮预览（自右侧滑入，点其他卡片切换、点空白 / Esc 关闭，浏览场景下持续显示）；**双击**进入编辑；**长按**（约 0.4s）等同单击（手势宽容，与编辑器长按呼出预览的习惯一致）；预览卡片头提供「打开笔记」按钮，把预览升级为进入编辑。卡片底部摘要高度自适应（不足 3 行时收缩，最多 3 行）。视图支持**网格/列表切换**（持久化）。卡片 ⋮ 菜单：常用区 = 收藏 / 移出常用 / 信息 / 删除笔记，收藏区 = 取消收藏 / 信息 / 删除笔记，笔记库区 = 重命名 / 信息 / 删除笔记库（删除红色警示置底）。

- FR-2.6.6 笔记信息：笔记 ⋮ 菜单（侧栏树 + 网格卡片）新增「信息」项，弹窗显示创建时间和最后修改时间。

### 2.6.1 标签

- FR-2.6.7 标签管理：创建 / 重命名 / 删除标签，支持自定义颜色（修改颜色弹窗提供 8 色预设色板 + 自定义拾色器）。标签名大小写不敏感、不可重名。
- FR-2.6.8 笔记打标签：笔记 ⋮ 菜单（侧栏树 + 网格卡片）新增「标签…」入口，打开管理标签弹窗——列出全部标签定义（色点 + 名称），勾选切换打标 / 取消，即时生效。
- FR-2.6.9 标签筛选：侧栏「标签」区显示所有标签，点击标签打开网格视图显示关联笔记。
- FR-2.6.10 标签存储（frontmatter）：标签随笔记 YAML frontmatter 的 `tags` 键存储，随文件移动 / 重命名 / 外部编辑天然跟随；标签定义（名称 / 颜色）存应用元数据；重命名 / 删除标签定义时自动改写关联笔记；未登记的 frontmatter 标签读取时自动注册；旧版元数据关联启动时自动迁移。预览 / 悬浮预览与网格卡片摘要不渲染 frontmatter（预览采用行级掩码，保持行级滚动同步映射）。
- FR-2.6.11 标签区折叠：侧栏「标签」区标题带展开箭头（与「笔记库」区一致的交互与视觉），标签较多时可收起，避免把下方区块（断链引用 / 回收站 / 笔记库）挤出可视区；收起态保留标签数量角标与「+」新建按钮，新建标签后自动展开；展开状态持久化。区块标题的点击行为不变（仍是打开标签网格）。

### 2.7 回收站

- FR-2.7.1 位置：工作区根目录 `.trash/`，不进入任何 git 仓库。
- FR-2.7.2 库 / 文件夹 / 笔记删除统一进回收站；条目记录原位置、类型、删除时间。
- FR-2.7.3 还原：回到原位置；原位置存在同名对象时自动追加「（已恢复）」后缀，不覆盖。
- FR-2.7.4 彻底删除（单条，需确认）与清空回收站（需确认）。
- FR-2.7.5 侧栏「回收站」单行入口，点击直达列表视图。
- FR-2.7.6 过期清理：保留天数可配置（7 / 30 / 90 天 / 永久保留，默认 30），应用启动时自动清理超期条目（本体与索引一并删除）。
- FR-2.7.7 容量上限：设置 → 通用可配置最大条目数（100 / 200 / 500 / 1000 / 不限，默认不限）；移入新条目与应用启动时，超出上限即按删除时间从旧到新永久删除（FIFO）。

### 2.8 Git 云同步（GitHub）

- FR-2.8.1 账号：设置 → 账号，粘贴 GitHub Personal Access Token 登录；含可展开的分步图文引导（打开创建页 → 生成 → 复制 → 粘贴登录），创建链接自动预填备注与权限；支持退出登录。
- FR-2.8.2 令牌安全：令牌存系统级加密存储（Electron safeStorage；Linux 无 keyring 时降级明文并警告）；仅通过每次调用的 `http.extraheader` 注入，不写入 `.git/config`；日志统一脱敏。
- FR-2.8.3 关联：库齿轮菜单 → 关联 Git 仓库；未登录时引导先登录。可选择已有仓库（列表可搜索）或新建仓库（可设公私有）；新建后自动使用 GitHub 返回的规范仓库名完成关联。
- FR-2.8.4 首次同步策略：远端有内容且本地为空 → 采用远端历史；远端为空 → 推送本地；两边都有 → rebase 合并。
- FR-2.8.5 日常同步（库菜单「立即同步」/ 编辑卡「同步」按钮）：提交本地全部变更 → rebase 拉取 → 推送。
- FR-2.8.6 冲突：rebase 冲突时保留冲突状态（不自动中止），弹出图形化解决界面；支持查看三方对比（本地/远端/共同祖先）、逐文件解决（接受本地版本、接受远端版本、手动编辑）、解决后继续同步或放弃所有更改（中止 rebase）。
- FR-2.8.7 解除关联：移除 origin，保留本地提交历史。
- FR-2.8.8 提交身份：优先使用登录用户名（`<user>@users.noreply.github.com`），未登录用占位身份；库内自动设 `core.quotepath false`。
- FR-2.8.9 状态展示：已关联的库显示徽标；编辑卡显示分支名、↑未推送 / ↓未拉取数量、未提交修改标记。
- FR-2.8.10 网络健壮性：同步等网络操作有 60 秒超时上限（超时即中止并提示，不无限等待）；常见网络故障（DNS 解析失败、无法连接、超时、连接中断、令牌失效、仓库不存在）以友好的中文提示呈现，原始报错仅记录日志文件。
- FR-2.8.11 网络代理：用户可为 Git 同步配置 HTTP/HTTPS 代理（地址 + 端口 + 可选凭据），配置存应用数据目录，仅在 git 调用时以 `-c http.proxy=…` 注入（与令牌同策略，不写入 `.git/config`）；提供「测试连接」反馈可达性（对 github.com 发起轻量 ls-remote，15 秒超时）。
- FR-2.8.12 同步入口：库齿轮菜单「立即同步」与编辑卡「同步」按钮；同步期间按钮呈加载态且不可重复触发。
- FR-2.8.13 内置 Git：应用随安装包附带平台对应的精简 Git 二进制（Windows MinGit busybox 版 / macOS·Linux Dugite-native）。
- FR-2.8.14 自动同步：可配置方式（关闭 / 定时 / 变更触发），仅对已关联远程仓库的笔记库生效；仅同步磁盘已保存内容，失败静默记日志，同步期间挂起文件监听，单轮未完成时跳过下一轮（定时模式）或在轮次结束后补跑（变更触发模式）。
  - 定时模式：按固定间隔（1 / 5 / 10 / 30 分钟）轮询。
  - 变更触发模式（v0.2.0 起）：保存笔记后 5 秒（防抖窗口，连续变更合并）触发一次同步，单轮未完成时新变更不丢弃，在轮次结束后补跑一轮收敛；定时/变更模式互斥；兼容旧 `autoSyncEnabled` 设置（true 自动迁移为 interval 模式）。
  - 交付方式：**随安装包内置**（非按需下载）；构建时由 `npm run fetch:git` 下载并按 SHA256 校验，解压到 `vendor/git/<platform>/`（不入库），electron-builder 收进 `resources/git/`，由安装包自身压缩载荷（实测 Windows 安装包 125.0 → 144.6 MB，增量 **+19.6 MB / +15.7%**）。
  - 运行时定位：零解压逻辑，按候选路径探测可执行文件（Windows `cmd/git.exe`、Linux `bin/git`）；不随应用引入解压依赖；安装后磁盘占用 +82 MB。
  - 检测时机：用户触发关联（FR-2.8.3）或同步（FR-2.8.5）时才检测 git 可用性，不在启动时打扰用户。
  - 检测逻辑：系统 git 可用 → 静默使用系统 git（无提示）；系统 git 不可用 + 内置 git 可用 → 弹窗询问「是否使用内置 Git？」；两者均不可用 → 弹窗提示安装 Git 并给出平台安装指引（降级兜底，仅在用户取消内置组件或归档损坏时可达）。
  - 用户选择持久化：弹窗选择后记住用户偏好（`settings.json` 的 `gitSource` 字段），后续同步不再重复弹窗；设置页提供「重置选择」按钮。
  - 与 GitHub 登录解耦：登录（FR-2.8.1）通过 REST API 完成，不需要 git 二进制，登录流程不受影响。
  - 设置页信息：通用标签页展示当前 Git 来源（系统/内置）及版本号。
  - 详见 [bundled-git-design.md](2026-09-10_bundled-git/bundled-git-design.md)。

### 2.9 界面布局与外观

- FR-2.9.1 三栏圆角卡片布局：灰色画布（间距统一 10px）上浮三张 8px 圆角卡片——侧栏、编辑卡片、预览卡片；欢迎 / 回收站 / 设置页使用同风格整页卡片。
- FR-2.9.2 侧栏结构：应用标识、「常用」「收藏」「回收站」（单行直达）、「笔记库」，底部设置按钮。「常用 / 收藏 / 标签 / 断链引用 / 回收站」分区可在设置 → 通用 → 侧栏菜单中分别显示 / 隐藏（「笔记库」始终显示）。编辑卡右下角的反向链接入口（FR-2.4.11.1）由设置 → 通用 → 编辑器 →「显示反向链接」开关控制。
- FR-2.9.3 编辑卡片：顶部为面包屑 + Git 状态 + 同步按钮 + 定位按钮（见 FR-2.3.7）+ 视图开关（预览收缩、专注模式、心流模式咖啡杯按钮，见 FR-2.9.8），下接格式工具栏，主体为编辑器。
- FR-2.9.4 预览收缩：顶栏按钮切换预览卡片显示/隐藏，隐藏时编辑卡片占满；状态持久化（重启保持）。
- FR-2.9.5 专注模式：四角方框按钮开启后隐藏侧栏只留编辑卡片；专注下仍可通过预览按钮呼出预览（编辑区与预览区各占 50%）；状态持久化。心流模式（FR-2.9.8）进入时复用本模式的隐藏行为与顶栏隐藏开关。顶栏隐藏时，编辑卡右下角显示**长条形状态区**（胶囊形、底色 + 描边、85% 不透明度），内容从左到右——Git 状态（分支图标、等宽分支名、未推送 / 未拉取、未提交、同步转圈；当前库是 git 仓库即显示，含未关联远端的本地库）、保存状态小圆点（静置隐去）、编辑模式三图标（所见即所得 / 心流 / 专注，各自激活时 accent 高亮）；悬停唤出顶栏时淡出。反向链接入口（FR-2.4.11.1）在该状态下自动上移到状态区上一行。
- FR-2.9.6 悬浮预览（编辑器，「一瞥」语义）：**长按**预览按钮（约 0.5s）或快捷键 **Alt+P** 呼出悬浮预览卡片——自右侧滑入、带阴影覆盖编辑区、不改变分栏布局。**回到写作即自动收回**：点击编辑区、开始输入、切换笔记、Esc / 卡片按钮 / 再点按钮 / Alt+P 任一即关闭，无需手动清理。卡片头提供「固定」按钮（磁铁图标）：一点即转正为常驻分栏预览（对应 FR-2.9.4 的显示状态）。
- FR-2.9.8 心流模式：一键进入沉浸创作（`Alt+W` / 编辑卡顶栏咖啡杯按钮）——自动隐藏侧栏、迷你导航条与顶栏，切换为所见即所得，开启打字机（推导式：设置为「关闭」时心流内按低位生效，用户选过高位 / 低位则沿用，不改写设置项）、写作栏宽（三档：窄 32 / 中 42 / 宽 52 字符，文本列含行号居中）与极微弱保存指示；`Esc` 一键退出并还原进入前的界面状态（侧栏 / 专注 / 预览 / 编辑形态，进入时快照），心流内的手动调整不影响退出还原；心流内保留 Ctrl+F 搜索、Ctrl+N 新建与 Alt+B 浮层侧栏；设置项在 设置 → 通用 → 心流模式（写作栏宽 / 回车音效）。属「心流模式」三期计划的第二期（三期均已实施，见 FR-2.9.9），设计见 [2026-09-23_flow-mode/](2026-09-23_flow-mode/flow-mode_design.md)。
- FR-2.9.9 心流模式回车音效：回车插入换行时播放程序合成的键盘音（Web Audio 合成，含随机微调；无音频文件、零体积、无版权）；音色四选一——**复古打字机**（默认，按实录音效特征重建：按键「咔」+ 推回车棘轮约 0.26s + 回车铃余振约 0.7s，整段约 1.0s）/ 推回车（棘轮，0.3s）/ 回车铃（0.8s）/ 轮换（三者依次交替）；默认关闭，设置 → 通用 → 心流模式提供开关、音色、音量滑杆（默认 60%）与「连续换行屏蔽音效」开关（默认开——快速连续换行只有第一次发声）；连续回车 120ms 限流；仅心流模式内生效，粘贴多行不发声；关闭开关即释放音频上下文。设计见 [2026-09-23_flow-mode/](2026-09-23_flow-mode/flow-mode_design.md)。
- FR-2.9.7 主题：浅色 / 深色 / 跟随系统 + 预设配色方案（暖色、冷色、高对比度），全界面颜色基于 CSS 变量；主题包导入：支持从 JSON 文件导入自定义主题（一组 CSS 变量覆盖文件，含浅/深两套）；导入时按 19 项变量白名单与取值规则校验，非法即拒绝并提示；自定义主题存应用数据目录 `themes/`，在设置页与内置预设并列，可删除，删除当前主题自动回退默认。详见 [theme-import_design.md](2026-09-14_theme-import/theme-import_design.md)。

### 2.11 插件系统（v2 M1–M4 已实施，v0.5.0 发布）

- FR-2.11.1 插件位于应用数据目录 `plugins/<id>/`，含 `manifest.json`（id / name / version / description / main / permissions）。
- FR-2.11.2 加载：总开关与单插件开关都开启时执行入口 `activate(ctx)`；`activate` 返回函数作为停用回调；应用启动时自动加载已启用插件。
- FR-2.11.3 首次运行自动放入示例插件作为开发模板；示例版本升级时自动覆盖（保留启用状态）。
- FR-2.11.5（v2 M1）**进程隔离**：每个插件运行在独立 utilityProcess；崩溃守护指数退避重启（1s/2s/4s/8s），连续 5 次自动停用并标记错误；停用 5s 超时强杀。
- FR-2.11.6（v2 M1）**能力网关与权限**：ctx 能力调用按 manifest.permissions 过滤，未声明直接抛错；require 白名单（插件目录内文件 + path/util/events）；权限确认对话框在首次启用与权限变化时展示中文说明。
- FR-2.11.7（v2 M1）**Tier 1 API**：notes 读写（含 vaults/list/tree/read/write/create，写侧防覆盖 hash）、事件订阅（note:saved / note:opened / vault:changed / sync:done）、通知、日志、命令注册；RPC 超时与内容大小限制、高频事件合并。
- FR-2.11.8（v2 M1）**命令**：插件注册的命令在设置页插件行显示并可运行。
- FR-2.11.9（v2 M2）**打包导入导出**：`.trace-plugin`（zip 自包含）导入（解压暂存 → 清单校验 → 权限确认弹窗含「未经市场审阅」警示 → 安装；同 id 为升级覆盖）与导出；zip-slip 与炸弹防护。
- FR-2.11.10（v2 M2）**插件私有存储**：`settings:persist` 权限对应的宿主托管 KV（`ctx.storage`），按插件隔离、随卸载清除。
- FR-2.11.11（v2 M2）**设置页详情与卸载**：运行状态 / 权限 / 崩溃历史 / 日志查看 / 存储占用；卸载 = 停用 + 删目录 + 清权限记录与私有存储。
- FR-2.11.12（v2 M3）**声明式 UI 扩展**：`editor:toolbar` 工具栏按钮（manifest `contributions.toolbar` 声明，命令驱动，插件不碰 DOM）与 `ui:status` 侧栏状态区（`ctx.status`，每插件一行，随插件停止清除）。
- FR-2.11.13（v2 M3）**类型包**：`trace-plugin-api`（packages/plugin-api，d.ts + JSDoc）提供 ctx 完整类型补全；已发布至 npm（v0.5.1 起随发版由 CI 自动发布，npm Trusted Publishing / OIDC，版本一致时自动跳过）。
- FR-2.11.14（v2 M4）**插件市场**：索引仓库 `imnot70/trace-plugins`（trace-plugins.json 登记 id/版本/资产/sha256/权限，增改走 PR 审阅）；应用内浏览安装（下载 → sha256 校验 → 复用导入管线）、更新检查与一键更新（权限新增需重确认）、下架标记（已装保留可用）；市场请求跟随 HTTP/HTTPS 代理设置。

## 3. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 平台 | Windows 10+、macOS、Linux（Ubuntu/Debian 优先），单实例运行 |
| 依赖 | 安装包已内置 Git（Windows/Linux），无需用户自行安装；系统已装 Git 时优先使用系统版本。缺失时（如 macOS 源码构建 / 用户取消内置组件）仅同步功能受影响，其余功能正常并给予安装指引 |

## 4. 交互与视觉规范

### 4.1 视觉

- 布局：灰色画布（`--bg-secondary`）+ 10px 统一间距 + 8px 圆角卡片；分隔条为透明间隙，悬停显示圆角细条。
- 主题：全部颜色走 CSS 变量（`--bg-*` / `--text-*` / `--accent` / `--danger` 等），Element Plus 变量映射到同一套变量。
- 危险操作：菜单项红色字体 + 悬停浅红底。

### 4.2 命名规则

- 禁止字符：`\` `/` `:` `*` `?` `"` `<` `>` `|` 与控制字符；不可点开头 / 点结尾；禁用 Windows 保留名（CON、PRN、AUX、NUL、COM1-9、LPT1-9）；长度 ≤ 100。
- 重名：大小写不敏感；库全局唯一，文件夹 / 笔记同父目录内唯一。
- 附件目录额外规则：最多 4 层，禁止 `.` / `..` 段，空值回退默认 `attachments`。

### 4.3 快捷键
