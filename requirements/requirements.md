## 0. 产品定位

Trace（中文名「笔迹」）是一款**本地优先**的轻量级 Markdown 笔记应用：

- 笔记以纯 Markdown 文件存储，**无私有格式**，任何编辑器都能打开；
- 每个笔记库是一个独立 git 仓库，天然支持**多设备同步与版本历史**；
- 支持 LaTeX 公式、图片粘贴、主题与插件；
- 跨平台：Windows / macOS / Linux（Ubuntu、Debian 系为主）。

三条产品原则：

1. **文件是唯一事实来源**——应用的所有数据（笔记、图片）都是磁盘上可见的普通文件，应用元数据（设置、收藏等）与笔记数据严格分离，不污染笔记库；
2. **不悄悄丢数据**——保存有外部修改检测，删除先进回收站，危险操作红色警示；
3. **对普通用户友好**——无需理解 git 也能完成云端同步，关键流程有分步引导。

## 1. 术语表

| 术语 | 含义 |
| --- | --- |
| 工作区 | 所有笔记库的父目录，默认 `~/Trace`，可更换 |
| 笔记库 | 工作区下的一个一级文件夹 = 一个独立 git 仓库，按主题组织 |
| 文件夹 | 笔记库内的子目录，可多级嵌套（最多 6 层） |
| 笔记 | 一份 `.md` 文件，文件名即笔记名 |
| 附件目录 | 库内存放粘贴图片的目录，可配置（默认 `attachments`） |
| 回收站 | 工作区下的 `.trash/`，应用级删除缓冲区 |
| 专注模式（Zen） | 隐藏侧栏、只保留编辑卡片的沉浸式编辑状态 |
| 悬浮预览 | 覆盖在编辑区上方的浮动渲染预览卡片 |

## 2. 功能需求

### 2.1 工作区

- FR-2.1.1 首次启动自动创建默认工作区 `~/Trace` 并启用。
- FR-2.1.2 可在设置中更换工作区目录（目录选择器 + 应用按钮），生效后刷新全部数据并关闭已打开的笔记；工作区目录必须可写。
- FR-2.1.3 更换工作区后，笔记库列表、回收站随新目录切换。

### 2.2 笔记库

- FR-2.2.1 创建：输入名称，系统校验（见 4.2）；创建后出现在侧栏「笔记库」区。
- FR-2.2.2 重命名：库齿轮菜单中操作，校验规则同创建。
- FR-2.2.3 删除：确认弹窗提示「库中全部内容将一并移入回收站」；删除后库整体（含 `.git`）进入回收站。
- FR-2.2.4 库行操作按钮：齿轮（关联 Git / 立即同步 / 解除关联 / 重命名 / 删除笔记库）与 `+`（新建文件夹 / 创建笔记）。

### 2.3 文件夹与笔记

- FR-2.3.1 层级：文件夹最多 6 层（不含笔记库），超限提示「已达最大层数」。
- FR-2.3.2 创建 / 重命名 / 删除：文件夹与笔记均支持；重名校验与非法字符校验贯穿所有操作（规则见 4.2）。
- FR-2.3.3 笔记名即文件名（自动补 `.md`），界面显示去 `.md`。
- FR-2.3.4 行操作按钮（悬浮显示）：文件夹有 `+`（新建文件夹 / 创建笔记）与 `⋮`（重命名 / 删除）；笔记有 `⋮`（重命名 / 删除 / 收藏）。
- FR-2.3.5 删除类菜单项以红色字体警示；删除操作有确认弹窗。
- FR-2.3.6 侧栏树实时反映磁盘变化（chokidar 监听，git 拉取 / 外部编辑器改动均能感知；git 同步期间挂起监听避免自我触发）。
- FR-2.3.7 定位笔记：在侧栏树中展开并高亮目标节点（库 / 文件夹 / 笔记），滚动到可视区，高亮约 2 秒后淡出。入口：编辑卡顶栏「定位」按钮（十字准星图标，定位当前笔记）；网格卡片 ⋮ 菜单「在侧栏中定位」（库 / 文件夹 / 笔记卡片均有）。侧栏收起时自动恢复侧栏；专注模式下以浮层侧栏展示定位结果，不打断沉浸。
- FR-2.3.8 位置上下文：应用维护「最近导航到的库与文件夹」（打开笔记 / 网格钻入库或文件夹 / 侧栏点击库与文件夹行均更新；库重命名 / 删除时迁移与清理），作为 `Ctrl+N` 新建笔记的目标；无上下文时兜底第一个笔记库。

### 2.4 笔记编辑器

- FR-2.4.1 形态：左侧源码编辑（CodeMirror 6）+ 右侧实时渲染预览，中间分隔条可拖拽调整比例（20%–80%），双向滚动按源码行号映射联动（见 [preview-enhancement-design.md](2026-09-09_preview-enhancement/preview-enhancement-design.md)）。
- FR-2.4.7 内嵌 HTML：笔记中的内嵌 HTML 在预览中渲染（markdown-it `html: true`）；渲染输出经 DOMPurify 白名单净化（剥除脚本 / 样式注入 / base / 表单 / 事件属性，防同步投毒笔记的视觉钓鱼与导航劫持），CSP 追加 `form-action 'none'`。
- FR-2.4.8 链接跳转：预览中链接（markdown 与原始 HTML 两种来源）统一事件委托处理——外部 http(s) 链接经系统浏览器打开；指向库内笔记的相对路径链接（`./笔记.md` 等）在应用内直接打开；断链渲染为删除线样式并轻提示。该"相对引用解析 → 校验 → 打开"管道与二期 wiki 双链共享。
- FR-2.4.2 语法支持：完整 Markdown + LaTeX 公式（行内 `$...$`、块级 `$$...$$`，KaTeX 渲染）+ 代码块语法高亮（常用 16 种语言）+ GFM 任务列表（`- [x]` / `- [ ]`，只读复选框）。
- FR-2.4.3 工具栏（编辑卡片内）：撤销、重做、加粗、斜体、删除线、H1/H2、引用、行内代码、代码块、链接、行内公式、公式块。
- FR-2.4.4 保存：编辑后 1 秒防抖自动写盘（可关闭）；`Ctrl+S` / `Cmd+S` 手动保存。
- FR-2.4.5 外部修改保护：以磁盘内容 hash 比对。
  - 无未保存改动 → 静默重载；
  - 有未保存改动 → 顶部横幅提供「放弃本地修改并重载 / 保留本地修改继续编辑」；
  - 本地保存时若磁盘 hash 不一致 → 拒绝写入，防止覆盖；
  - **回声抑制**：应用自身的保存写入同样会触发文件监听，检测前先读磁盘与最后写入内容比对，一致即忽略——横幅只在真正的外部修改时出现。
- FR-2.4.6 笔记标题面包屑显示在编辑卡片顶部，含未保存圆点标识。

### 2.5 图片与附件

- FR-2.5.1 粘贴 / 拖入图片：自动保存到库内附件目录，文件名加时间戳前缀防重名，笔记中插入相对路径引用。
- FR-2.5.2 附件目录可配置（设置 → 通用）：相对库根的多级路径（如 `media/image`，最多 4 层）；修改仅对之后粘贴的图片生效。
- FR-2.5.3 预览中相对路径图片通过自定义协议 `trace-vault://<库名>/<路径>` 加载显示。

### 2.6 收藏与常用

- FR-2.6.1 收藏：笔记 `⋮` 菜单收藏 / 取消；侧栏「收藏」区直达。
- FR-2.6.2 收藏跟随：笔记重命名 / 父文件夹或库重命名 / 删除时自动更新或清理引用。
- FR-2.6.3 常用：最近打开的笔记，时间倒序，上限 20 条。
- FR-2.6.4 高亮规则：侧栏（常用 / 收藏 / 树）中当前打开笔记的行带底色，且仅当正处于编辑视图时显示。
- FR-2.6.5 卡片网格交互（常用 / 收藏 / 笔记库网格）：笔记卡片**单击**呼出悬浮预览（自右侧滑入，点其他卡片切换、点空白 / Esc 关闭，浏览场景下持续显示）；**双击**进入编辑；**长按**（约 0.4s）等同单击（手势宽容，与编辑器长按呼出预览的习惯一致）；预览卡片头提供「打开笔记」按钮，把预览升级为进入编辑。卡片 ⋮ 菜单：常用区 = 收藏 / 移出常用 / 删除笔记，收藏区 = 取消收藏 / 删除笔记，笔记库区 = 重命名 / 删除笔记库（删除红色警示置底）。

### 2.7 回收站

- FR-2.7.1 位置：工作区根目录 `.trash/`，不进入任何 git 仓库。
- FR-2.7.2 库 / 文件夹 / 笔记删除统一进回收站；条目记录原位置、类型、删除时间。
- FR-2.7.3 还原：回到原位置；原位置存在同名对象时自动追加「（已恢复）」后缀，不覆盖。
- FR-2.7.4 彻底删除（单条，需确认）与清空回收站（需确认）。
- FR-2.7.5 侧栏「回收站」单行入口，点击直达列表视图。

### 2.8 Git 云同步（GitHub）

- FR-2.8.1 账号：设置 → 账号，粘贴 GitHub Personal Access Token 登录；含可展开的分步图文引导（打开创建页 → 生成 → 复制 → 粘贴登录），创建链接自动预填备注与权限；支持退出登录。
- FR-2.8.2 令牌安全：令牌存系统级加密存储（Electron safeStorage；Linux 无 keyring 时降级明文并警告）；仅通过每次调用的 `http.extraheader` 注入，不写入 `.git/config`；日志统一脱敏。
- FR-2.8.3 关联：库齿轮菜单 → 关联 Git 仓库；未登录时引导先登录。可选择已有仓库（列表可搜索）或新建仓库（可设公私有）；新建后自动使用 GitHub 返回的规范仓库名完成关联。
- FR-2.8.4 首次同步策略：远端有内容且本地为空 → 采用远端历史；远端为空 → 推送本地；两边都有 → rebase 合并。
- FR-2.8.5 日常同步（库菜单「立即同步」/ 编辑卡「同步」按钮）：提交本地全部变更 → rebase 拉取 → 推送。
- FR-2.8.6 冲突：rebase 冲突时自动中止，列出冲突文件并保持本地工作区不变，由用户手动处理。
- FR-2.8.7 解除关联：移除 origin，保留本地提交历史。
- FR-2.8.8 提交身份：优先使用登录用户名（`<user>@users.noreply.github.com`），未登录用占位身份；库内自动设 `core.quotepath false`。
- FR-2.8.9 状态展示：已关联的库显示徽标；编辑卡显示分支名、↑未推送 / ↓未拉取数量、未提交修改标记。
- FR-2.8.10 网络健壮性：同步等网络操作有 60 秒超时上限（超时即中止并提示，不无限等待）；常见网络故障（DNS 解析失败、无法连接、超时、连接中断、令牌失效、仓库不存在）以友好的中文提示呈现，原始报错仅记录日志文件。
- FR-2.8.11 网络代理：用户可为 Git 同步配置 HTTP/HTTPS 代理（地址 + 端口 + 可选凭据），配置存应用数据目录，仅在 git 调用时以 `-c http.proxy=…` 注入（与令牌同策略，不写入 `.git/config`）；提供「测试连接」反馈可达性（对 github.com 发起轻量 ls-remote，15 秒超时）。
- FR-2.8.12 同步入口：库齿轮菜单「立即同步」与编辑卡「同步」按钮；同步期间按钮呈加载态且不可重复触发。
- FR-2.8.13 内置 Git：应用随安装包附带平台对应的精简 Git 二进制（Windows MinGit busybox 版 / macOS·Linux Dugite-native）。
  - 交付方式：**随安装包内置**（非按需下载）；构建时由 `npm run fetch:git` 下载并按 SHA256 校验，解压到 `vendor/git/<platform>/`（不入库），electron-builder 收进 `resources/git/`，由安装包自身压缩载荷（实测 Windows 安装包 125.0 → 144.6 MB，增量 **+19.6 MB / +15.7%**）。
  - 运行时定位：零解压逻辑，按候选路径探测可执行文件（Windows `cmd/git.exe`、Linux `bin/git`）；不随应用引入解压依赖；安装后磁盘占用 +82 MB。
  - 检测时机：用户触发关联（FR-2.8.3）或同步（FR-2.8.5）时才检测 git 可用性，不在启动时打扰用户。
  - 检测逻辑：系统 git 可用 → 静默使用系统 git（无提示）；系统 git 不可用 + 内置 git 可用 → 弹窗询问「是否使用内置 Git？」；两者均不可用 → 弹窗提示安装 Git 并给出平台安装指引（降级兜底，仅在用户取消内置组件或归档损坏时可达）。
  - 用户选择持久化：弹窗选择后记住用户偏好（`settings.json` 的 `gitSource` 字段），后续同步不再重复弹窗；设置页提供「重置选择」按钮。
  - 与 GitHub 登录解耦：登录（FR-2.8.1）通过 REST API 完成，不需要 git 二进制，登录流程不受影响。
  - 设置页信息：通用标签页展示当前 Git 来源（系统/内置）及版本号。
  - 详见 [bundled-git-design.md](2026-09-10_bundled-git/bundled-git-design.md)。

### 2.9 界面布局与外观

- FR-2.9.1 三栏圆角卡片布局：灰色画布（间距统一 10px）上浮三张 8px 圆角卡片——侧栏、编辑卡片、预览卡片；欢迎 / 回收站 / 设置页使用同风格整页卡片。
- FR-2.9.2 侧栏结构：应用标识、「常用」「收藏」「回收站」（单行直达）、「笔记库」，底部设置按钮。
- FR-2.9.3 编辑卡片：顶部为面包屑 + Git 状态 + 同步按钮 + 定位按钮（见 FR-2.3.7）+ 视图开关（预览收缩、专注模式），下接格式工具栏，主体为编辑器。
- FR-2.9.4 预览收缩：顶栏按钮切换预览卡片显示/隐藏，隐藏时编辑卡片占满；状态持久化（重启保持）。
- FR-2.9.5 专注模式：四角方框按钮开启后隐藏侧栏只留编辑卡片；专注下仍可通过预览按钮呼出预览（编辑区与预览区各占 50%）；状态持久化。
- FR-2.9.6 悬浮预览（编辑器，「一瞥」语义）：**长按**预览按钮（约 0.5s）或快捷键 **Alt+P** 呼出悬浮预览卡片——自右侧滑入、带阴影覆盖编辑区、不改变分栏布局。**回到写作即自动收回**：点击编辑区、开始输入、切换笔记、Esc / 卡片按钮 / 再点按钮 / Alt+P 任一即关闭，无需手动清理。卡片头提供「固定」按钮（磁铁图标）：一点即转正为常驻分栏预览（对应 FR-2.9.4 的显示状态）。
- FR-2.9.7 主题：浅色 / 深色 / 跟随系统，全界面颜色基于 CSS 变量；预留自定义主题包（一组变量覆盖文件）。

### 2.10 设置中心

设置页三个标签：

- FR-2.10.1 账号：GitHub 登录态管理（含新手引导，见 FR-2.8.1）。
- FR-2.10.2 插件：插件总开关、已装插件列表与启停。
- FR-2.10.3 通用：工作区路径、主题、编辑器字号（12–22px）、自动保存开关、附件目录；快捷键速查表（全局 / 编辑器分组展示）；关于信息（应用版本）。
- FR-2.10.5 设置返回编辑：编辑笔记期间打开设置时，页头显示正在编辑的笔记名并提供「返回编辑」按钮（回到原笔记并自动聚焦）；`Ctrl+,` 为开关语义，`Esc` 同样可返回；无编辑中的笔记时返回欢迎页。
- FR-2.10.4 网络代理：Git 同步的 HTTP/HTTPS 代理设置入口（见 FR-2.8.11），位于设置 → 通用。

### 2.11 插件系统（v1 骨架）

- FR-2.11.1 插件位于应用数据目录 `plugins/<id>/`，含 `manifest.json`（id / name / version / description / main / permissions）。
- FR-2.11.2 加载：总开关与单插件开关都开启时执行入口 `activate(ctx)`；`ctx` 提供 `notify(message)` 与 `logger`；`activate` 返回函数作为停用回调；应用启动时自动加载已启用插件。
- FR-2.11.3 首次运行自动放入示例插件作为开发模板。
- FR-2.11.4 v1 不开放第三方市场与完整 API。

## 4. 交互与视觉规范

### 4.1 视觉

- 布局：灰色画布（`--bg-secondary`）+ 10px 统一间距 + 8px 圆角卡片；分隔条为透明间隙，悬停显示圆角细条。
- 主题：全部颜色走 CSS 变量（`--bg-*` / `--text-*` / `--accent` / `--danger` 等），Element Plus 变量映射到同一套变量。
- 危险操作：菜单项红色字体 + 悬停浅红底。

### 4.2 命名规则

- 禁止字符：`\` `/` `:` `*` `?` `"` `<` `>` `|` 与控制字符；不可点开头 / 点结尾；禁用 Windows 保留名（CON、PRN、AUX、NUL、COM1-9、LPT1-9）；长度 ≤ 100。
- 重名：大小写不敏感；库全局唯一，文件夹 / 笔记同父目录内唯一。
- 附件目录额外规则：最多 4 层，禁止 `.` / `..` 段，空值回退默认 `attachments`。

### 4.3 快捷键

> 修饰键分层：**Ctrl+字母** = 应用通用动作（含编辑器格式化），**Alt+字母/数字** = 界面 / 视图切换，**Esc** = 分级回退。完整速查表内置在 设置 → 通用 → 快捷键（单一数据源渲染，见 `src/renderer/src/config/shortcuts.ts`）。

**全局**（对话框打开时除 Esc 外不响应）：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + S` | 手动保存当前笔记 |
| `Alt + P` | 呼出 / 收起悬浮预览（编辑视图） |
| `Alt + 1 / 2 / 3 / 4` | 打开常用 / 收藏 / 回收站 / 笔记库网格（再按一次关闭，回收站仅进入） |
| `Ctrl/Cmd + ,` | 打开设置（设置页内再按 / `Esc` = 返回编辑中的笔记，无则回欢迎页） |
| `Alt + F` | 进入 / 退出专注模式 |
| `Alt + B` | 显示 / 隐藏左侧栏 |
| `Alt + V` | 显示 / 隐藏预览区 |
| `Ctrl/Cmd + N` | 新建笔记（目标 = 「当前位置」上下文：最近导航到的文件夹，见 FR-2.3.8） |
| `Esc` | 分级回退：关闭悬浮预览 → 返回上级文件夹 → 关闭网格 |

**编辑器内**（焦点在编辑器时生效）：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + B` / `Ctrl/Cmd + I` | 加粗 / 斜体（选中包裹或插占位符，见 FR-2.4.3） |
| `Ctrl/Cmd + Shift + X` | 删除线 |
| `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` | 撤销 / 重做 |

### 4.4 对话框与提示

- 新建 / 重命名共用名称对话框：输入即时格式校验，提交时后端校验重名并在对话框内显示错误（不关闭）。
- 删除确认：笔记单独确认；文件夹 / 库提示内容连带删除。
- 操作结果以轻提示（成功）或红色提示（失败）反馈。

## 5. 质量与交付基线

- 打包：electron-builder，Linux deb + AppImage、Windows NSIS、macOS DMG；应用图标由脚本生成（`npm run icon`）。
- 开发命令：`dev` / `build` / `test` / `typecheck` / `lint` / `dist` / `dist:deb` / `icon`（详见 README）。
- 调试：`TRACE_CDP=<端口> npm run dev` 可经 CDP 连接渲染进程；`TRACE_TEST_USERDATA=1` 以临时数据目录启动隔离实例。

## 6. 已知局限

- 列表项内的块级公式（`- $$...$$`）渲染不理想（markdown-it-texmath 局限）。
- 专注模式与悬浮预览在极窄窗口（<1080px）下编辑区最小宽度受限。
- 回收站无容量上限与过期自动清理。
- Windows 10 无窗口级模糊效果支持（当前未启用窗口透明/模糊，见二期）。
