# 项目需求

## 项目简述
这是一个轻量级的笔记软件项目。
主要支持平台：Windows、Mac、Linux，其中Linux以Ubuntu及Debian系为主。
主要支持的特性：
- 同步git仓库
- 文件内容以markdown文件保存
- 支持Latex
- 支持插件功能
- 支持主题功能

## 文件结构
用户可以按主题创建“笔记库”（即最顶层目录），“笔记库”下可以再创建多子目录，子目录可以多级创建，最下层内容为“笔记”（即markdown文件）
大致结构图：
```plaintext
-笔记库1
 |-一级子目录1
   |-一级子目录1的笔记1
   |-一级子目录1的笔记2
 |-一级子目录2
   |-二级子目录1
    |-二级子目录1的笔记1
    |-二级子目录1的笔记2
 ...
```
## UI设计
UI采用左右分栏的设计，左侧边栏主要是菜单功能。从上至下分别是
- 常用
- 收藏
- 回收站
- 笔记库
除了上面的三个菜单，在左边栏的左下角设计一个小齿轮，这是“设置按钮”，里面可以进行登录（登录git账号），插件管理，和系统设置

## 主要功能
### 笔记库管理
- 创建笔记库，用户可以按主题创建笔记库，创建时需要用户输入笔记库的名称，系统需要检查名称是否与已有的笔记库重名。创建好的笔记库会列出在左侧的笔记库菜单中，同时笔记库的名字右侧会有一个设置按钮（用小齿轮表示）和一个加号按钮，其中设置按钮提供以下功能：
    - 关联git仓库（如果用户没有登录github账号则提示用户需要登录github）
    - 重命名
    - 删除笔记库
加号按钮提供以下功能：
    - 创建子目录
    - 创建笔记
- 笔记库重命名，在笔记库设置按钮中提供的功能，用于修改笔记库的名字，重命名时需要检查是否和已有的笔记库重名
- 删除笔记库，在笔记库设置按钮中提供的功能，删除的笔记库和库中的内容会被放入回收站（可以通过左侧栏的回收站查看已经删除的库），如果笔记库中有内容（子目录或笔记文件）则提示笔记库中的内容会被一起删除。
- 创建子目录，可以创建子目录。具体见子目录管理中的创建子目录功能
- 创建笔记，可以创建笔记文件。具体见笔记管理中的创建笔记功能

### 子目录管理
- 创建子目录，笔记库下可以创建子目录，创建时用户需要输入目录名称，系统需要检查名称是否与当前目录/库下已有的目录重名。子目录的名字右侧会有一个设置按钮（这里使用三个点表示）和一个加号按钮，其中设置按钮提供以下功能
    - 重命名
    - 删除子目录
加号按钮提供以下功能：
    - 创建子目录
    - 创建笔记
- 子目录重命名，在子目录设置按钮中提供的功能，用于修改子目录的名字，类似库的重命名，需要检查是否重名
- 删除子目录，在子目录设置按钮中提供的功能，删除的子目录和子目录中的内容会被放入回收站。如果子目录中有内容（次级的子目录或笔记文件）则提示子目录中的内容会被一起删除。
- 创建子目录，子目录中可以再创建子目录，目前先限制为最多6层（不算最顶层的笔记库）。第6层子目录再创建子目录则提示“已达最大层数”
- 创建笔记，可以创建笔记文件。具体见笔记管理中的创建笔记功能

### 笔记管理
- 创建笔记，库和子目录下可以创建笔记文件，创建笔记文件后用户需要输入笔记名称，系统需要检查名称是否与当前路径下的笔记重名。笔记名的右侧会有一个设置按钮（用三个点表示），设置按钮提供以下功能：
    - 重命名
    - 删除笔记
    - 收藏笔记
- 重命名，修改笔记的名字，需要检查是否重名
- 删除笔记，删除前会弹出确认窗口，用户确认后再把文件移动到回收站
- 收藏笔记，收藏后的笔记会添加到左侧的收藏目录下
- 编辑笔记内容，允许用户对当前笔记内容进行编辑，需要支持以下内容：
    - Markdown格式内容
    - Latex格式内容
