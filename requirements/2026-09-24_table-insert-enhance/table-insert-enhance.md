# 表格插入增强（尺寸输入 + 表内跳转）需求

> 创建：2026-09-24 ｜ 状态：**已实施（已随 v0.8.0 发布）**——实施记录与实测矩阵见 [table-insert-enhance_design.md](table-insert-enhance_design.md) 第 7 节
> 关联：FR-2.4.16（表格插入）—— 本次新增 FR-2.4.20 / FR-2.4.21，并**修订 FR-2.4.16 的交互**
> 本文档记录需求结论（做什么、为什么）；技术方案见 [table-insert-enhance_design.md](table-insert-enhance_design.md)。

## 1. 背景与目标

FR-2.4.16 的表格插入目前固定为「2 列表头 + 1 行空数据行」。用户提出两点增强：

1. **可指定行列数**：`Ctrl+T` 后输入「行 列」（如 `5 6`）即插入 5 行 6 列表格；直接空格 / 回车 → 默认表格。
   ⚠️ 用户明确指出**原方案缺交互**：「用户输入后也不知道自己输入的是否正确」——因此本条的目标不只是「能输入」，而是**输入过程全程有可见反馈**（当前将插入几行几列、按空格会发生什么、非法输入怎么提示）。
   ⚠️ **不做倒计时自动插入**（2026-09-24 用户实测反馈）：原方案「1 秒无输入即按默认插入」在有了浮层之后反而抢跑——提示还没看清就被插入了。现改为浮层**一直等待**用户输入数字、按空格 / 回车确认或 `Esc` 取消。
2. **表内 Tab 跳转**：插入表格后 `Tab` / `Shift+Tab` 在单元格之间前后跳转（现在是浏览器默认行为——Tab 把焦点移出编辑器），便于逐格填表。

## 2. 功能需求

### FR-2.4.20 表格尺寸输入（带实时反馈）

**触发与流程**（`Ctrl+T` 或工具栏「表格」按钮）：

1. 触发后**不立即插入**，而是进入「尺寸输入」状态，并在**光标附近弹出浮层**：
   - 显示当前将插入的尺寸（默认 `2 行 × 2 列`）；
   - 显示操作提示：`输入行列数（如 5 6）· 空格/回车 插入 · Esc 取消`；
   - 显示**逐状态精确的脚注**（按当前状态说明空格 / 回车会发生什么）：未输入 →「按空格或回车插入 2 行 × 2 列」；正在输第一个数 →「空格继续输入列数 · 回车插入 5 行 × 2 列」；行数已提交 →「空格或回车插入 5 行 × 2 列」。
2. **输入**：连续输入数字 + 空格，第一个数 = 行数、第二个数 = 列数；**每次按键浮层实时更新**（如输入 `5` → 显示 `5 行 × 2 列`；再输入 `6` → `5 行 × 6 列`），非法/超限输入给出明确提示（红字 + 上限说明）。
3. **确认方式**：
   - **空格**：正在输入第二个数时作为分隔（提交行数、等待列数）；其余情况（什么都没输 / 行数已提交 / 行列都齐）→ 按当前尺寸立即插入；
   - **回车**：用当前尺寸立即插入（只给了行数时列数取默认 2）；
   - `Ctrl+T` 再按一次 → 用当前尺寸插入（等同回车）。
4. **取消**：`Esc` 取消，不插入任何内容。
5. **不会自动插入**：浮层一直等待用户操作（输入数字 / 空格 / 回车 / `Esc` / 点击他处），不设倒计时——避免提示来不及看就被插入。
6. **输入期间不写入文档**：数字/空格只被浮层与状态机消费，不落进正文；取消后正文无任何痕迹。
7. **失焦即取消**：点击编辑区其它位置 / 窗口失焦 → 取消（不插入）。

**默认尺寸**：2 行（含表头）+ 2 列（与 FR-2.4.16 现状一致）。**取值范围**：行 1–50、列 1–20（超限时浮层提示并取上限）。

### FR-2.4.21 表格内 Tab / Shift+Tab 跳转

- 光标位于**表格内**时：
  - `Tab` → 跳到**下一个单元格**（按行优先顺序，从表头行开始），并选中该单元格内容（便于直接覆盖输入）；空格单元格则把光标放到其中；
  - `Shift+Tab` → 跳到**上一个单元格**；已在第一个单元格时 → 光标移到表格**上一行行尾**（离开表格）；
  - 在**最后一个单元格**按 `Tab` → **追加一行**（列数与表头一致）并跳到新行第一格，便于连续填表；
- 光标**不在表格内**时：`Tab` 行为不变（浏览器默认：移动焦点）；
- 补全浮层打开时 `Tab` 仍用于接受补全（不被表格跳转抢占）；
- 源码模式与所见即所得模式均可用。

## 3. 非目标（本期不做）

- 表格的可视化编辑（拖拽列宽、增删行列按钮、对齐设置）；
- 鼠标网格选择器（Word 式 hover 网格）——浮层已提供数字输入，网格选择留待后续；
- 表格内方向键的二维导航（只做 Tab / Shift+Tab 的线性跳转）；
- 多行/多列批量粘贴与自动扩表；
- 记住「上次使用的表格尺寸」（如需要可后续加为设置项）；
- **在设置中提供「表格默认行列值」**（2026-09-24 用户提出）：让 `Ctrl+T` 提示浮层的默认尺寸可配置。**与同类编辑器设置攒批处理**——用户明确希望等「编辑方面类似的设置」攒够一批后一起实现，故暂不单独立项。

## 4. 验收标准

1. `Ctrl+T` 后**立即出现浮层**，显示默认尺寸与操作提示；此时不插入任何内容；
2. 输入 `5 6 ` → 插入 5 行 6 列的表格（表头 + 4 行数据），光标落在首列表头；浮层在输入过程中实时显示 `5 行 × 6 列`；
3. 输入 `5 6` 后按回车 → 同样插入 5 行 6 列；
4. 只输入 `3 ` 后按回车 → 插入 3 行（列数取默认 2）；
5. `Ctrl+T` 后长时间不操作（≥2 秒）→ **不插入任何内容**，浮层保持等待；
6. `Ctrl+T` 后直接按空格或回车 → 立即插入 2 行 2 列；
7. `Esc` 取消：不插入任何内容，正文与光标位置无残留（浮层消失）；
8. 输入期间正文不出现输入的数字；点击其它位置取消后同样无残留；
9. 超限输入（如 `99 99`）浮层给出上限提示，插入时按上限（50 行 / 20 列）执行；
10. 表格内 `Tab` / `Shift+Tab` 逐格跳转、顺序正确（表头 → 数据行，行优先）；最后一格 `Tab` 追加一行；`Shift+Tab` 在首格时离开表格；
11. 表格外 `Tab` 仍移动焦点；补全浮层打开时 `Tab` 接受补全；
12. 既有单元测试不回归；新增尺寸状态机与表内跳转的单元测试。

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 输入被误写进正文 | 数字/空格/回车在编辑器键位层被拦截消费（不进入事务），取消时正文零残留；实测断言正文不变 |
| 用户触发后不知如何继续 / 忘记浮层存在 | 浮层不自动消失、脚注逐状态写明「按空格 / 回车会发生什么」；`Esc` / 点击他处随时退出，且从不写入正文 |
| 浮层遮挡正文 / 闪烁 | 浮层为轻量绝对定位卡片，跟随光标一次定位（交互期间光标不动）；不使用 tooltip / popper 机制，避开仓库已知的闪影问题 |
| `Tab` 抢占既有行为（焦点移动 / 补全接受） | 只在「光标位于表格内且补全浮层未打开」时接管；其余情况返回未处理，行为不变 |
| 追加行导致误改文档 | 仅在最后一格 `Tab` 时发生（与 Word / 表格工具一致），且可一步撤销 |
