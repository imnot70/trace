## 会话 2：两个 UI 回归修复（`6f91f35` / `ec070ad`）

1. **侧栏按钮/菜单失效**（用户报：设置齿轮、创建库按钮点了没反应）：v0.3.4 的「悬浮提示统一」把 el-tooltip 包到了交互元素上。三种坏法：tooltip 嵌套、tooltip 包整行、tooltip 包 el-dropdown 触发器。修复 = tooltip 只留非交互元素，触发器回退原生 title。**通用禁令已写入 AGENTS.md「代码约定」**。
2. **闪影复发（新触发路径）**：交接文档记录的闪影是「锚点行被删除」；本次是「`.side-row-actions` 仅 hover 时显示，点击菜单外鼠标离行 → 按钮组 display:none → 收起中的 popper 失锚跳 (0,0)」。修复 = 下拉打开期间行挂 `menu-hold` class 保持按钮组可见，关闭后 300ms 再隐藏（`onVaultMenuVisible` / `onMenuVisible`）。实测两种路径残影为 0。
3. **移除侧栏全部 EP 悬浮提示**（用户反馈与常用/收藏风格不一致）；库行描述保留原生 title（0.3.2 功能）。
4. ⚠️ 本次会话曾在清理菜单代码时误删 `Menu.setApplicationMenu(null)`——会导致 Electron 默认菜单回归（autoHideMenuBar 只隐藏不删除，Alt 唤出）。已恢复并注释。**这行调用永远不要删。**
